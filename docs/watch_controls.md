# 見守り（Watch）シーンの操作方法

**装着した人が、画面の見え方だけで判断できるように書いてある。**
内部の名前（クラス名・変数名）は出さない。

この資料はコードから実際の割り当てを拾って書いた（`WatchInput.cs` /
`WatchView.cs` / `WatchSceneBootstrap.cs`）。**推測で埋めていない。**

---

## 入力の全一覧

| 入力 | 何が起きるか |
|---|---|
| **左手グリップ**（握る） | **表示の段が切り替わる。** 握るたびに 2つの段を往復する |
| **右手 A ボタン** | **実時間と再生が切り替わる。** 前回のセッションの記録を流し直す |
| 左手トリガー | **未使用** |
| 左手 X ボタン | **未使用** |
| 左手 Y ボタン | **未使用** |
| 左手スティック（倒す・押し込む） | **未使用** |
| 右手グリップ | **未使用** |
| 右手トリガー | **未使用** |
| 右手 B ボタン | **未使用** |
| 右手スティック（倒す・押し込む） | **未使用** |
| Meta ボタン | アプリの外に出る（システムの動作。**押すと部屋の見え方がずれることがある**） |

**左手グリップは強く握り込む必要がある**（半分ほどでは反応しない）。
握り直すたびに 1回進む。押しっぱなしでは進まない。

---

## 段の一覧と、切り替えたときに画面上何が変わるか

段は 2つある。**いま何段目かは、パネルの上から 3行目に出ている。**

### 段「足元」

- **自分の足元に黄色いマスが 1つだけ出る。** 他には何も出ない
- 歩くと、黄色いマスが足の下をついてくる
- **床が青くも灰色にもならない**（何も敷かれていない状態に見える）

**何を見る段か**: 黄色いマスが自分の足の下から離れないか。

### 段「カバレッジ」

- **床一面に青いマスが敷き詰められる。** 部屋の形に沿って敷かれ、
  **壁の向こう側には出ない**
- 足元には黄色いマスが 1つ乗る
- **HMD を外す・追跡を失うと、青いマスが全部灰色に変わる**（マスは小さくなる）。
  かぶり直すと青に戻る
- **部屋の外（扉の向こう・隣の部屋）には何も出ない。** 灰色ですらない

**何を見る段か**: 青い面の縁が実際の壁の手前で止まっているか。
灰色に変わるところを見たいときもこの段。

---

## パネルはどこに出るか

- **部屋の中の決まった場所に浮いている**（頭に追従しない）。
  アプリを起動した向きから見て**正面のやや下、目の高さより少し低い位置**に、
  1.4 m ほど離れて出る
- **黒い半透明の四角の中に、白い文字が 5行**
- **見失ったときの探し方**: アプリを起動したときに向いていた方向へ体ごと向き直る。
  それでも見つからないときは、**その場でゆっくり一周する**。
  パネルは動かないので、必ずどこかにある

**文字が 5行あることを確かめること。** 5行より少なく見えるときは、
下の行が黒い四角の外へはみ出している可能性がある（過去に起きた不具合）。

### 5行それぞれの意味

| 行 | 何が書いてあるか | 見るところ |
|---|---|---|
| 1 | どのビルドか（シーン名・ブランチ・コミット・部屋の識別子） | **報告するときにこの行を読み上げる**。ここが違うと別のアプリを見ている |
| 2 | **いま測れているかどうか** | 「測れている」なら床が青い。「測れていない」なら床が灰色 |
| 3 | **いま何段目か** | 左手グリップを握ったときにここが変われば、切り替えは効いている |
| 4 | **色の意味**（凡例） | 黄＝足元 / 青＝測れている床 / 灰＝測れていない床 / 何も無い＝部屋の外 |
| 5 | **警告** | **「異常なし」なら正常。** 何か書いてあれば、その内容を報告する |

**5行目に何か出ていたら、それを読み上げてほしい。**
出る可能性があるもの: 記録できない / 描画を切り捨て / 格子を新規作成 / 再生中。
3つ以上同時に起きたときは「3件: ○○ ほか」のように件数が出る。

---

## 実時間と再生

- **右手 A ボタン**で切り替わる
- 再生中は、**5行目の警告に「再生中 123/1559」のように出る**（いま何件目か）
- 再生中は**前回のセッションの動きが流れる**。自分が動いても足元のマスは追従しない
- **前回の記録が無いときは切り替わらない**（実時間のままになる）。
  そのときは 5行目に「再生元なし」と出る

---

## アプリの起動と終了（PC 側）

**順序が決まっている。** 入れ替えるとセッションの冒頭を取り落とす。

| # | やること | コマンド |
|---|---|---|
| 1 | ビルド | `scripts\build_quest.ps1 -Watch` |
| 2 | 端末へ入れる（**起動はしない**） | `scripts\deploy.ps1 -Watch` |
| 3 | **記録を始める（アーム）** | `scripts\capture_session.ps1` |
| 4 | アプリを起動 | `scripts\restart_app.ps1` |
| 5 | — セッション — | |
| 6 | **記録を止める** | `scripts\stop_capture.ps1` |

- **3 の前に 4 をやってはいけない。** 起動時にしか出ない情報（部屋の形、格子、
  平面の一覧）を取り落とす
- `deploy.ps1` はアプリを起動しない。起動は必ず `restart_app.ps1`
- `build_quest.ps1` と `deploy.ps1` は **`-Watch` を必ず付ける**。
  付けないとエラーになる（別のシーンを入れてしまう事故を防ぐため）
- アプリを終了するには **Meta ボタン**を押してホームへ戻る。
  PC 側から止めるなら `restart_app.ps1` を実行し直せば入れ直しになる

## 記録されるもの

- **PC 側**: `Logs\session_日時.log`（画面に出ている値はすべてここにある）
- **端末側**: 動きの記録。次回のセッションで**再生元**になる

**数値はログから後で読む。装着中に見るのは「そう見えるか」だけでよい。**
