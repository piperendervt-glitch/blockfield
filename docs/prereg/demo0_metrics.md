# Demo 0 事前登録 — アンカー固定＋オクルージョン＋描画性能の基礎検証

登録日: 2026-08-08 / 対象タグ: demo-0.x（完了時にフリーズ）
方針: blockfieldはゲームデモ。本登録は「動くものを確認する」ための
軽量ガードレールであり、統計的厳密性は求めない。

## スコープ
- T1: USE_SCENE ランタイム権限フロー → AROcclusionManager 有効化
- T2: 平面検出 → レイキャスト＋トリガーでジオラマ原点確定 →
      スパシャルアンカー固定・再起動後復元
- T3: ダミーボクセル（箱の集合）をアンカー基準表示、以下を測定

## メトリクス
- M1（アンカー安定性）: アプリ再起動→アンカー復元を2回試行。
  原点位置に現実のマーカー（テープ）を貼り、復元後のズレが
  目視で「1ブロック（4cm）以内」なら合格。定規測定は不要
- M2（描画性能・記録のみ）: 箱1万個を表示して快適に動くか体感確認。
  余裕があれば2万・4万と増やし、カクつきを感じた水準をメモに残す。
  Go/No-Go対象外（性能改善はDemo 1以降の仕事）
- M3（オクルージョン成立）: 机の縁の奥にブロックを置き、腕の長さ
  程度の距離から見て机に隠れること。エッジのちらつきは許容。
  「BlockVerseで感じた実在感に近いか」の主観メモも残す

## Go/No-Go
- Go条件: M1合格 かつ M3合格
- No-Go時: 原因を1行メモしてから対処（基準自体は変更しない）
