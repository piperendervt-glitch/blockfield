# Demo 8 第2段 — エディタでの事前確認手順（死の場）

実機に行く前に PC で「死の場が墓場として見えるか」「墓場のまわりに
草が増えるか」を目視する手順。実機セッションは1回5分・装着中は
操作できないため、可視化の妥当性は必ずここで確認してから実機へ行く。

## 前提
- Unity Editor で本プロジェクトを開く（CLI テストと同時実行は不可）
- メニュー `Tools > BlockField > Terrain Preview`

## 手順1: 死の場が「点」として立つのを見る

死の場は τ≈333 ティック（減衰 0.003）と**極端に長寿命**なので、
恐怖場や獲物場と違って「消えずに溜まっていく」のが特徴。

1. Terrain Preview を開く
2. `Seed = 12345`、`50x50`、起伏スケール 24 のまま **Generate**
3. **「場を表示 (E1 / Demo 8)」にチェック**、`表示する場 = Death`
4. **Simulate 100 ticks** を押す

**期待**: 最初はほぼ真っ暗（死がまだ起きていない）。
100ティックあたりから**紫の点**がぽつぽつ現れる。

**注意**: すぐに出なくても不具合ではない。餓死は3,000ティックで
50〜80件程度しか起きないため、100ティックでは数個が普通。

## 手順2: 墓場が育ち、消えないことを見る

1. **Simulate 100 ticks** をさらに **29回**押す（合計3,000ティック）
   - 途中 500 / 1,000 / 2,000 ティックでも見ておくと変化が分かる
2. `表示する場 = Death` のまま真上から見下ろす（右上ギズモの Y 軸）

**期待**:
- 紫の点が**増え続け**、3,000ティックで **70セル前後**（実測 71 / 69 / 73）に
  なる。適性セル約2,225のうち約3%
- 一度点いた紫は**ほとんど薄くならない**。恐怖場（τ≈33）や
  獲物場（τ≈20）が数十ティックで消えるのと対照的
- 点は 1〜2セルの小さな塊。拡散は1パス（L≈1.3セル）なので
  にじみは狭い

**ここで見分ける不具合**:
- 紫が一面に広がる → 拡散パス数か拡散率が上がっている
- 紫が出てすぐ消える → 減衰が大きすぎる（τ の設計が失われている）
- 3,000ティックで10セル未満 → 死が起きていないか deposit が届いていない

## 手順3: 墓場のまわりに草が増えているか（M2 の目視）

1. 手順2の状態のまま、`表示する場 = Death` で**紫の濃い塊を1つ選ぶ**
2. その位置を覚えたまま「場を表示」のチェックを**外す**
3. 同じ場所を拡大して、緑の立方体（草）・黄色の立方体（花）を数える
4. 紫が無い平地の同じ広さと見比べる

**期待**: 墓場のまわりの方が植物がやや多い、または少なくとも
**明らかに少なくはない**。

**目視で「明確に多い」とは見えない可能性が高い。それが正常。**
ヘッドレスの実測で墓場の植物密度は 10.3%、それ以外は 8.9%。
差は約1.2倍で、数セルを目で見て分かる差ではない。
**M2 の判定は目視ではなく数値で行う**（パネルの `Grave P:` 行）。

目視で見るべきなのは「墓場が草の生えない不毛地帯になっていないか」。
死は餌の乏しい所で起きるので、養分効果が無ければ墓場は
**周囲より草が薄い土地**になる（対照の実測 2.9% 対 9.3%）。
そうなっていなければ養分効果は効いている。

## 手順4: 3つの場を並べて取り違えないか確認

実機では色だけが手がかりなので、隣り合う色を取り違えないかを見る。

1. `表示する場` を Vegetation → Fear → Prey → Death と順に切り替える
2. そのつど同じ視点で見る

**期待する色**:

| 場 | 色 | 見え方 |
|---|---|---|
| Vegetation | 緑 | 広く薄く全体に敷かれる |
| Fear | 赤 | 狼の通り道に線状。数十ティックで消える |
| Prey | 青 | 草食獣の周りに直径5セル程度のにじみ |
| Death | **紫** | 小さな点。消えずに溜まる |

赤（恐怖）と紫（死）を取り違えないことが重要。
紫は明度を上げず彩度で分けてある。**見分けられなければ色を変える。**

## 手順5: パネルの数値が出ているか（実機で判定するのはこちら）

死の場の判定は目視では足りないため、数値をパネルとログの両方に出した。
Terrain Preview には実機パネルが無いので、実機セッションで見る項目を
ここに書いておく。

- `Fld avg/max ... D:xxx/xxx` — 死の場の平均と最大
- `Grave P: 10.3% vs 8.9% = 1.17 (ctrl 0.33)` — 墓場と他の植物密度、その比
  - **1.0 が基準ではない**。養分効果が無い対照でも 0.33 にしかならない
    （餓死は餌の乏しい所で起きるため）。0.33 より十分大きいかで見る
- `Avoid: 62% (ctrl 55)` — 恐怖の低い方へ動いた割合（M3）

同じ内容が30秒ごとに `[DebugPanel]` としてログにも出る（CLAUDE.md の規約）。

## 実機で見るときの操作（参考）
- 右手B: 通常 ⇄ 診断モード
- 診断モード中に**左手Y**: マーカー → 植生(緑) → 恐怖(赤) → 獲物(青)
  → **死(紫)** → 非表示 を巡回
