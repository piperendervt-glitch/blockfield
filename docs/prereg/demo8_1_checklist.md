## 各項目の詳細

### M1（けもの道の創発）— 合格
実機の診断モードで恐怖場（赤）が**線状の道**として視認でき、
狼の軌跡表示（直近40ティック、新しいほど白い）と赤い場の対応も追えた。
エディタプレビューでも細長い筋を確認している。
ヘッドレスの裏付け: 恐怖場の高値セルの連結成分は細長さ 6.0〜8.0
（塊状なら1に近い）。

### M2（迂回行動）— 未達
事前登録の指標では比が 199% / 233% / 119% と**逆方向**に出た。
交絡を除くため同一run内で正規化した指標でも、w_fear=1.5 で 0.44/0.46/0.76、
対照(w_fear=0) で 0.34/0.56/0.72 と差は小さく符号も一定しなかった。

原因4点（prereg に記録済み、いずれも実装の誤りではない）:
1. 恐怖場を読むのは**摂食モード（hunger > 0.5）のときだけ**。読む時間が約半分
2. `moveChance = 0.5` なので向きを決めても半分は動かない
3. **狼が頻繁に絶滅**し恐怖場が空の期間が長い
4. 恐怖の濃い所にいた個体は**捕食されて消える**ため、回避が無くても
   生き残りは薄い所に偏る（指標が効果を分離できていない）

Go条件外のため判定は進めるが、**第2段以降での改善対象**とする。
対処の選択肢: 満腹時も恐怖を読む / 指標を作り直す / 狼の絶滅を先に直す。

### M3（コード削減）— 合格
削除:
- `FindNearestHerbivore` … 半径6セル以内の全個体走査 O(N²)（22行、分岐4）
- `ChaseStep` … 主軸→副軸の直進追跡（17行、分岐4）
- `TryStep` … 追跡専用の移動（18行、分岐3）
- `k_WolfSightRadius` … 「視界半径」という個体側の概念そのもの（1行）
合計 **58行・分岐11を削除**。

追加:
- `FindPreyGradientFacing` … 4近傍の獲物場を見るだけ O(1)（20行、分岐3）
- `FindAdjacentHerbivore` … 捕食の成立判定、4近傍の固定順（26行、分岐5）
合計 46行・分岐8。

差し引き **12行・分岐3の削減**。行数以上に重要なのは、狼から
「獲物の位置を知る」という概念が消え、個体数に依らない O(1) になったこと。

### M4（決定論）— 合格
3シードとも同一シード・同一ティック数で ContentHash 一致。
恐怖場・獲物場がハッシュに含まれることも検証済み（片方を書き換えると変わる）。

### M5（捕食率の維持）— 合格
置換前の実測 17.83回/1000t（箱庭3シード×2,000ティック）に対し、
獲物場の範囲調整後は **14.67回/1000t = 82%**。部屋スケールでも
39.83 対 48.83 = 82%。基準の「半減しない（50%以上）」を上回る。

### M6（性能・記録）— 72FPS 維持
場が2枚増えた後も 72FPS を維持。

## 実機セッション後の調整: 獲物場の範囲

実機で「草食獣の分布と対応しているが、範囲が大きすぎて平地のほとんどが
青くなる」と観察された。実測すると**高値セルが全体の 92.5%** で、
勾配がほぼ平坦＝場としての情報量が失われていた。

deposit 0.3 / 拡散 0.4×3パス / 減衰 0.05（到達距離 L≈2.4セル）へ変更し、
**高値面積 92.5% → 15.8%**（部屋 14.8%）と局所化。捕食率は 82% を維持した。
狼が場を読む近傍を広げる補償は不要だった。掃引の全数値は prereg に記録。

## 途中経緯（実機判定が2回不能になった原因と修正）

1. **場のオーバーレイのY座標ズレ**: 観測面の worldY に敷いていたが、
   実際の地表はその上に積もった雪地形1〜4ブロック分上（実測: 観測面0.01m に対し
   地表0.080m）。生き物と場が一致して見えなかった。
   ワールドの表層高さに敷くよう修正。**SimCore の場は正しかった**
   （植物セル上の植生場は全体平均の5.3〜6.5倍、最大セルと最寄り植物の距離0セル）。
2. **色の退行**: 飢餓の色分けを解除するとき `_BaseColor` に白を書き込んでいたため、
   診断モードに一度入ると全個体が白くなった。プロパティブロックごと外すよう修正し、
   適用時も種の色に乗算するようにした。
3. **形状による識別**: 色は照明・場のオーバーレイ・飢餓表現と競合して識別子に
   ならなかったため、上から見た輪郭で3種を区別できる形にした（足の追加を含む）。
   形は EntityShape に集約し実機とエディタプレビューで共通化。
4. **マーカーの破棄漏れ**: 作り直しでメッシュだけ捨てて GameObject を残していたため、
   「非表示にしても緑の枠が残る」状態になっていた。
