# Demo 5b 事前登録 — バランス探索

登録日: 2026-08-09 / 対象タグ: demo-5b.x
方針: roadmap Demo 5b に対応。Demo 8 第1段で恐怖場・獲物場が
入った後のダイナミクスで、絶滅も爆発もしない範囲を探索する。
以後の Demo（第2段以降、Demo 9/10）の判定装置として生態系を
安定させることが目的。

## 背景（実測）
- 狼の絶滅頻度: 3シード中1〜2で全滅（Demo 8 第1段の記録）
- 狼が全滅すると恐怖場が空になり、第2段以降の判定が不能になる
- Demo 3 の偏り: 5070ティックで餓死1067・捕食63・出生3
- Demo 5a で密度は正規化済み（動物密度0.88%）

## スコープ
- ヘッドレスでのパラメータ探索（実機セッションは最小限）
- 探索対象: 繁殖率・繁殖クールダウン・hunger進行速度・
  捕食成功条件・植物のスポーン率と成長・各場のτ
- 回帰テスト化（安定範囲をテストで固定する）
- 表示・UIの変更は行わない

## メトリクス
- M1（狼の存続）: 5シード×5000ティックで、狼の全滅が
  0/5 シード。最低個体数が全シードで1以上
- M2（爆発の不在）: 各種の個体数が上限（密度基準）に
  張り付き続けない。上限到達時間の割合が50%以下
- M3（振動の健全性）: 個体数が単調減少や単調増加ではなく、
  捕食-被食の振動（Lotka-Volterra的な位相差）が見られる。
  植物→草食獣→狼の順に山が来る位相関係を定量
- M4（決定論の維持）: ContentHash 一致
- M5（回帰テスト化）: 安定条件が EditModeテストとして固定され、
  以後のパラメータ変更で崩れたら検出できる
- M6（実機確認・記録のみ）: 実機で5分回して各種が生存

## Go/No-Go
- Go条件: M1 かつ M2 かつ M4 かつ M5
- M3 は望ましいが必須としない（振動が出なくても絶滅・爆発が
  なければ判定装置としては足りる）
