### 各項目の補足
- **M2**: 第2回セッションで、正面を向いた状態で切り替えても正面にブロックが

- **M5**: VRモードで 72FPS を維持（地形11,093ブロック＋外殻82,865ブロック、

### 途中経緯（2つの不具合と原因）

**1. パススルーが消えなかった（第1回セッション）**
- 症状: 左手XでVRへ切り替えても現実映像が見えたまま。
- 原因: Meta Quest のパススルーは**カメラ映像の描画ではなく OpenXR の
  コンポジションレイヤー**だった。com.unity.xr.meta-openxr の
  MetaOpenXRCameraSubsystem が Provider.Start() で CreatePassthroughLayer()、
  Stop() で DestroyPassthroughLayer() を呼ぶ。つまりレイヤーを止められるのは
  **ARCameraManager.enabled** だけで、初版が触っていた ARCameraBackground と
  背景色のアルファでは止まらなかった。
- 修正: SetPassthroughEnabled で ARCameraManager を切る。
- 反省: このとき `[VrMode]` `[Passthrough]` を capture_session.ps1 のタグ列挙に
  追加し忘れ、「切替が呼ばれたのか」を事後に判定できなかった。
  タグ列挙をやめ Unity ログ行をまとめて拾う方式に変えた。

**2. 切替時に視野内だったジオメトリだけが消えた（第2回セッション前）**
- 症状: VRへ切り替えた瞬間に**視野内だった方向だけ**が真っ黒。
  振り向いた先にはブロックがあった。
- 切り分け: セッションログに再メッシュも破棄も無く、**ジオメトリの破棄ではない**
  ことを先に確定（仮説「可視チャンクのメッシュ破棄」を否定）。描画時の破棄と判断。
- 原因: シェーダーの遮蔽判定は `_IsOcclusionOn` で分岐する
  （OcclusionComputation.hlsl）。この値と深度テクスチャ・XR_HARD_OCCLUSION
  キーワードを流しているのは AROcclusionManager ではなく **ARShaderOcclusion**。
  AROcclusionManager だけを切っても ARShaderOcclusion は生きたままなので、
  `_IsOcclusionOn` は 1 のまま深度テクスチャが**切替時点のフレームで凍結**し、
  その凍結フレームが覆う方向だけが遮蔽され続けた。症状の非対称性が
  そのまま説明できる。
- 修正: PassthroughController が ARShaderOcclusion も切る。MRへ戻すときは
  深度の供給元を先に戻してからシェーダー側を戻す。

### 残課題
- **壁のギザギザ（グリッドの向き）**: 別タスク。WallFace 平面の最大面積のものから
  部屋の主軸ヨー角を求め、観測グリッドをその角度に合わせて回転させる。
  回転角も観測データに含めて M4（同じ観測から同じ地形）を保つこと。
- 床下3層は室内から見えないため、性能が問題になれば削ってよい。

## 録画方法（Quest 3 標準機能）

出典: [Meta 公式ヘルプ「How to record video on Horizon OS and Meta Quest」](https://www.meta.com/en-gb/help/quest/516228089650875/) /
[Capture MR and VR Apps for Publishing](https://developers.meta.com/horizon/resources/video-capture-mr-vr/)

### 手順A: ユニバーサルメニューから（確実）
1. 右手コントローラの **Meta ボタン**を押してユニバーサルメニューを開く
2. **カメラ**（Camera）を選択
3. **動画を録画**（Record video）を選択
4. 視界の中央に**赤い点**が出れば録画中
5. 停止はカメラアプリから、または手順Bのショートカットを繰り返す

### 手順B: コントローラのショートカット（速い）
- 右手 **Meta ボタンを押したまま、右トリガーを長押し**で録画開始
- 同じ操作で停止

**注意**: メタボタンの単独長押しは再センタリング（座標系のリセット）であって
録画ではない。録画は上記のとおり「押しながらトリガー」。

### 保存先と PC への取り出し
- ヘッドセット内の **Files**（Media / Recents フォルダ）または **Gallery** アプリ
- 端末上の実パス（実測で確認済み）: `/sdcard/Oculus/VideoShots/`
  ファイル名は `com.piperender.blockfield-YYYYMMDD-HHMMSS-0.mp4`
- **PC への取り出しはスクリプトで行う**:
  ```
  powershell -NoProfile -ExecutionPolicy Bypass -File scripts\pull_recordings.ps1        # 最新1件
  powershell -NoProfile -ExecutionPolicy Bypass -File scripts\pull_recordings.ps1 -All   # 全件
  ```
  保存先は `Recordings\`（無ければ作成）。同じサイズで取得済みのファイルは
  スキップするので、-All を繰り返しても大きい動画を引き直さない。
  `Recordings/` は .gitignore 済み（動画はリポジトリに入れない）。
- 終了コード: 0 = 成功 / 12 = adb 不明 / 14 = デバイス未接続 / 15 = 録画なし

### 画質の設定
- ユニバーサルメニュー → カメラ → 右上の **カメラ設定**（Camera settings）で
  画質・形式を変更できる
- 公式の既定値: 1920×1080 / 36fps（可変）/ 20Mbps
- **より高画質が要る場合**: Meta Quest Developer Hub (MQDH) の録画が最高品質
  （最大 2160p / 60fps / 40Mbps。USB接続が必要）。公開用の映像はこちらを推奨

### 録画時の設定メモ（本プロジェクト固有）
- 録画は **VRモード**（左手X）で行う。MRモードだと現実の部屋が映り込む
- パネル（FPS等のデバッグ表示）が映り込むため、公開映像では
  パネルを消すか、画角から外して撮る

## 実装メモ（実機で見えるはずのもの）
- 外殻は**別グリッド**。天井を地形グリッドに入れると World の表層高さ探索が
  天井を拾って生態系が全滅するため。MR では非表示。
- 壁の足元 24cm には G4 の境界ブロック（灰色 Stone）が残る。外殻（暗い青灰）
  とは色が違うので、幅木のような帯に見える。仕様どおりで不具合ではない。
- 外殻ブロック数の実測見積り: 壁12,848＋天井5,427＋床下16,281＝34,556。
  床下は室内からは見えないが、地形に穴があるときに床を閉じる役割がある。
