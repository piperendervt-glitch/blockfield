| 入力 | 動作 |

| 左手 **X** | **MR ⇄ VR 切替**（新規） |
| 右手 B | 部屋地形の表示モード切替（0 通常 ⇄ 1 診断） |
| 右手 A | 積もり方のシード巡回（地形と生態系が作り直される） |
| 右手 トリガー / グリップ | 設置 / 破壊 |

**割り当ての変更**: 事前登録では「右手A長押し1秒」だったが**左手X**にした。
右手Aの短押しはシード巡回に割り当て済みで、長押しと共存させると
「離すまで短押しか長押しか確定できない」ため既存機能に1秒の遅延が入る。
左手Xは Demo 4.5 G7 で箱庭の表示トグルを廃止したときに空いている。

## 録画方法（Quest 3 標準機能）

出典: [Meta 公式ヘルプ「How to record video on Horizon OS and Meta Quest」](https://www.meta.com/en-gb/help/quest/516228089650875/) /
[Capture MR and VR Apps for Publishing](https://developers.meta.com/horizon/resources/video-capture-mr-vr/)

### 手順A: ユニバーサルメニューから（確実）
1. 右手コントローラの **Meta ボタン**を押してユニバーサルメニューを開く
2. **カメラ**（Camera）を選択
3. **動画を録画**（Record video）を選択
4. 視界の中央に**赤い点**が出れば録画中
5. 停止はカメラアプリから、または手順Bのショートカットを繰り返す

### 手順B: コントローラのショートカット（速い）
- 右手 **Meta ボタンを押したまま、右トリガーを長押し**で録画開始
- 同じ操作で停止

**注意**: メタボタンの単独長押しは再センタリング（座標系のリセット）であって
録画ではない。録画は上記のとおり「押しながらトリガー」。

### 保存先と確認
- ヘッドセット内の **Files**（Media / Recents フォルダ）または **Gallery** アプリ
- PC へ回収する場合:
  `adb pull /sdcard/Oculus/VideoShots/ Logs/` （実際のパスは Files で確認する）

### 画質の設定
- ユニバーサルメニュー → カメラ → 右上の **カメラ設定**（Camera settings）で
  画質・形式を変更できる
- 公式の既定値: 1920×1080 / 36fps（可変）/ 20Mbps
- **より高画質が要る場合**: Meta Quest Developer Hub (MQDH) の録画が最高品質
  （最大 2160p / 60fps / 40Mbps。USB接続が必要）。公開用の映像はこちらを推奨

### 録画時の設定メモ（本プロジェクト固有）
- 録画は **VRモード**（左手X）で行う。MRモードだと現実の部屋が映り込む
- パネル（FPS等のデバッグ表示）が映り込むため、公開映像では
  パネルを消すか、画角から外して撮る

## 実装メモ（実機で見えるはずのもの）
- 外殻は**別グリッド**。天井を地形グリッドに入れると World の表層高さ探索が
  天井を拾って生態系が全滅するため。MR では非表示。
- 壁の足元 24cm には G4 の境界ブロック（灰色 Stone）が残る。外殻（暗い青灰）
  とは色が違うので、幅木のような帯に見える。仕様どおりで不具合ではない。
- 外殻ブロック数の実測見積り: 壁12,848＋天井5,427＋床下16,281＝34,556。
  床下は室内からは見えないが、地形に穴があるときに床を閉じる役割がある。
