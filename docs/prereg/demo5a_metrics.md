# Demo 5a 事前登録 — 密度基準の正規化

登録日: 2026-08-09 / 対象タグ: demo-5a.x
方針: パラメータ探索は行わない。スケール変更への機械的な追従のみ。

## スコープ
- SimParams のスポーン上限・頻度を「セル数あたりの密度」で定義
- 箱庭（2,500セル）時代の実測密度を基準に部屋スケールへ換算
- 適性セル数（suitability > 0 のセル）を基準にするか、
  総セル数を基準にするかは実装時に判断し理由を記録

## メトリクス
- M1（密度の回復）: 部屋スケールで、視界内に常時植物が見え、
  動物が複数頭確認できる。実機で目視
- M2（餓死の減少）: パネルの餓死累計の増加ペースが
  Demo 4.5 セッション時より明確に緩やかになる
- M3（決定論の維持）: 同一シード＋同一ティック数で
  ContentHash 一致。EditModeテスト
- M4（性能・記録のみ）: 個体数増加後も72FPS維持

## Go/No-Go
- Go条件: M1 かつ M3
- No-Go時: 原因を1行メモしてから対処（基準は変更しない）
