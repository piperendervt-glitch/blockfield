# Demo 8 第4.5段 事前登録 — 進化本体(変異の導入)

登録日: 2026-08-12 / 対象タグ: demo-8.4.5.x
方針: roadmap v11 第4.5段に対応。繁殖時の重み継承(第3段で実装済み、
変異なしの片親クローン)に変異を加え、行動重みを淘汰される形質に
変える。中心の問い: 「進化は群れの回廊(w≈2.4)を自力で発見できるか」

## 前提(確定済みの土台)
- 継承の基盤: EntityWeights の値コピー(Simulation.cs 繁殖処理)。
  変異の挿入点は1箇所、RNG 消費順は facing → 変異に固定(第4段
  調査で確認済み)
- ベースライン: 豚=羊は中立浮動(48シード、p=0.31)。変異導入後に
  種間で重みが分岐したら、それは初期条件でなく進化が作った差
- 群れのトレードオフの実在: 利益=繁殖効率(K3-K4結合)、
  害=過密絶滅(w=1.2 で餓死率が改善しながら絶滅 8/48)
- アブレーション済み: death→veg は固定(係数0で生態系が縮退する —
  実測: 3000ティックで草の総量 −59.8%、餓死率 +687%、出生 −87%。
  **絶滅は起きず、低水準の均衡で安定する**(50,000ティック×48シードで
  ギルド絶滅 0/48・狼の全滅 0/48。追記1 参照)。「種火」機構の詳細は
  coupling_ablation.md)。trample→veg は切っても安定(進化開放の
  第2候補だが本段では扱わない — 変数を絞る)
- 「生存=評価」構造の保護条項(roadmap v10): 本段の進化は評価関数を
  持たない。生態系そのものが選択を実行する

## スコープ
- K1: 変異の実装 — 繁殖時、子の重み各成分にガウスノイズを加算
  (mutationRate: 成分ごとの変異確率 / mutationSigma: 変異幅)。
  RNG 消費は決定論的に固定(消費順と回数を明記)
- K2: 重みの観察 — PopulationLog に種ごとの重み平均・分散を追加。
  認知範囲指標を追加: Σ|w_i|×τ_i(時間深度)と Σ|w_i|×L_i(空間半径、
  L は各場の拡散到達距離)。「何を覚える系に進化したか」を1数値で
  追う(theory_notes、Levin の Cognitive Light Cone の測定翻訳)
- K3: 進化対象の重みの決定 — 本段は移動重み(forage/wander の
  全場重み)を開放する。colonySelfWeight を含む。
  結合行列の係数は固定(アブレーションの結論)。
  **K3 は原理的に進化対象とする範囲の定義であり、実際の開放は
  実験ごとに段階的に行う。E1 は colonySelfWeight の1次元のみ、
  以降の実験で次元を広げる際は本 prereg に追記する**
- K4: 判定

## 実験設計(2系統)

### 実験E1: 回廊の探索(中心実験)
- 初期値: 全個体 colonySelfWeight = 0(群れの回廊の外)。
  他の重みは現行の確定値
- 変異: colonySelfWeight のみ開放(まず1次元で。他は固定)
- 走行: longrun(10万ティック級)×複数シード
- 問い: w の集団平均は回廊(≈2.4)へ向かうか。
  予想される結果は3通りで、いずれも価値がある:
  (a) 回廊到達 → 群れの適応的意義が系内で実証される
  (b) 0 付近に留まる → 群れに利益はあるが進化的到達経路がない
  (勾配が w=0 付近で平坦 — K3-K4 結合は場が立って初めて効く)
  (c) 過密絶滅への暴走 → 系レベルの淘汰の観察(w を上げすぎた
  個体群は絶滅で消える — 個体淘汰と系淘汰の綱引き)

### 実験E2: 中立形質の浮動(対照実験)
- E1 と同一構成で、選択圧が(ほぼ)ないはずの重み1成分を開放
  (候補: 狼の w_colony — 群れ度が草食獣の1/5 で弱い)
- 問い: 変異-浮動の力学だけでどれだけ分布が広がるか。
  E1 の動きが「選択」か「浮動」かを判定する物差しになる
- 判定: E1 の重み平均の移動量が、E2 の浮動の幅(95%区間)を
  超えること — これが「進化した」の操作的定義

## 「進化した」の定義(事前固定)
以下のいずれかが 48シード(または longrun 複数シード)で成立:
- D1: 重み平均の有向移動 — E2 の浮動幅を超える系統的な移動
- D2: 分散の動態 — 収束(安定化選択)または発散(分断化の兆候)が
  浮動対照と有意に異なる
- D3: 種間分岐 — 豚と羊の重みプロファイルが分離
  (ベースライン=同一 から)
記録項目: 認知範囲指標(Σw×τ, Σw×L)の時間推移

## 変異パラメータの決定
- mutationSigma の初期候補: 現行重みのスケールの 5〜10%
  (w_colony=2.4 に対し 0.1〜0.25)
- mutationRate 初期候補: 1.0(全繁殖で変異)から。
  掃引: sigma × rate の2次元、まず5シード粗掃引 →
  「浮動が観察でき、かつ即時絶滅しない」帯を特定 → 48シード
  または longrun で確定
- 掃引条件数が20を超えたらサロゲート導入を検討(roadmap v10)

## Go/No-Go
- Go 条件: K1(決定論を保った変異) ∧ K2(観察の実装) ∧
  E1・E2 が完走し「進化した/しなかった」がD1〜D3で判定できること
- 注意: E1 の結果(a)(b)(c)はいずれも Go。「群れに進化しなかった」
  は失敗ではなく発見である
- M(安定性): 変異導入で基準構成(現行確定値からの開始)の生態指標が
  壊れないこと — 変異あり・現行初期値の48シードが第4段の
  合格範囲内(変異は平均を変えないはずなので、壊れたら
  sigma が大きすぎる)

## リスクと想定される論点
- 致死領域: w 大で過密絶滅(8/48@w=1.2、48シード×3000ティックの実測)。
  進化がここへ暴走するシードは「系レベル淘汰の観察」として記録し、
  絶滅率の基準からは分離して扱う(E1 の問い自体が絶滅を含むため)。
  **death→veg の側には致死領域が無い**ことが実測で分かった(追記1)ので、
  致死領域として想定するのは w_colony の上側だけである
- 変異の RNG がストリームをずらす: 第4段以前との ContentHash
  比較は不可(既知)。同一実装内の決定論のみ検証
- 世代時間: 平均繁殖間隔から1世代≈数百ティック。10万ティックで
  数百世代 — 浮動と選択の分離に足りるかは E2 が答える
- 片親クローン+変異 = 無性生殖の進化モデル。有性(交叉)は
  扱わない(将来の課題として記録)
- 種火の分離(vegetationFloor の再定義で death→veg を純粋な
  墓場効果に戻す)は本段では行わない(将来の整理課題)

# 追記1 (2026-08-12): death→veg の「絶滅の崖」は誤りだった

登録当日の修正。**登録時の記述が実測より強かった**ため、
実測に合わせて書き換え、その根拠として不足していた長期計測を実施した。

## 何が誤りだったか

登録時は「death→veg は固定(係数0付近に**絶滅の崖**)」と書いていた。
根拠にしたアブレーション(48シード×3000ティック)で実際に観測したのは
**生態系の縮退**(草の総量 −59.8%、餓死率 +687%、出生 −87%)であって、
絶滅ではない。同じ計測でギルド絶滅は 0/48、狼の全滅も 0/48 だった。
「崖」は測定ではなく予測であり、prereg の前提として不適切だった。

## 実測: 縮退は絶滅に至らず、低水準の均衡で安定する

48シード × **50,000ティック**、default と nutrient-off の対比:

| | 草食獣 | 狼 | 餓死率 | 捕食率 | 草/適性セル | ギルド絶滅 | 狼の全滅 |
|---|---:|---:|---:|---:|---:|---:|---:|
| default | 26.57 | 2.41 | 0.333 | 0.408 | 0.2485 | 0/48 | **14/48** |
| nutrient-off | 12.63 | 8.21 | 3.086 | 1.710 | 0.1198 | 0/48 | **0/48** |

推移(48シード平均):

| t | default 草食獣/狼/草 | nutrient-off 草食獣/狼/草 |
|---|---|---|
| 10,000 | 24.2 / 3.31 / 558 | 11.8 / 9.02 / 294 |
| 30,000 | 28.3 / 1.94 / 594 | 12.5 / 8.35 / 287 |
| 50,000 | 28.2 / 1.67 / 600 | 12.5 / 8.35 / 293 |

nutrient-off は t≈10,000 で**完全に平衡に達し、以後 40,000ティック
動かない**。絶滅は一度も起きない。答えは「低水準の均衡で安定する」である。

## 予想外の結果: 縮退したほうが狼にとって良い

**本条件のほうが狼が全滅する**(14/48 対 0/48)。理由は 4c で確定した機構の
裏返しだった:

| | 羊の近傍数 | 羊のペア距離 | 狼 |
|---|---:|---:|---:|
| default | 6.151 | 11.25 | 1.67 |
| nutrient-off | 0.112 | **26.09** | 8.35 |

nutrient-off の草食獣は**ほぼ一様分布**である(26.09 は一様分布の
理論値 26.07 とほぼ一致)。草が乏しく餓死率が9倍なので、個体は
ほとんどの時間を空腹＝**採餌モード**で過ごす。群れ重みは満腹時の
徘徊にしか掛からない(4c の設計判断)ので、**空腹な世界では群れが生じない**。
獲物が散らばったままなので狼は匂いを追える。

4c では「群れが獲物場を一点に集中させ、匂いで狩る狼の探索面積を消す」
ことを採餌配線の失敗として発見した。今回は逆方向から同じ機構が確認された
— **餌を減らすと群れが消え、捕食者が回復する**。

## 本 prereg への影響

1. 前提の記述を実測に合わせた(上記)
2. リスク欄の「致死領域」は w_colony の上側のみとした。
   death→veg の側には致死領域が無い
3. **「death→veg は固定」の根拠が変わった。** 当初の理由
   「係数0付近で世界が崩壊するので探索が振れると個体群ごと失われる」は
   成り立たない(崩壊しない)。ただし本段のスコープでは
   結合行列の係数は元から進化対象外(K3)なので、判断そのものは変わらない。
   結合係数を探索に開放するかは第4.5段の後に改めて判断する

## 4c の M5 への波及(本 prereg の範囲外だが記録する)

**default 構成は 50,000ティックでは M5 を満たさない**(狼の全滅 14/48 = 29%
が許容 25% を超える)。4c の M5 合格は 3,000ティックでの判定であり、
長時間では成り立たない。群れは時間とともに強まり(羊の近傍数 2.625@3,000t →
6.151@50,000t)、それにつれて狼が減り続ける(4.42 → 1.67)。

これは第4段の判定を覆すものではない(判定はティック数を明示して行われた)が、
**「安定」の主張には時間スケールが必ず付く**ことを示している。
longrun100(10万ティック)では狼がさらに減っている可能性が高く、
結果を読む際の前提になる。
再現: `--seeds 48 --ticks 50000 --conditions default,nutrient-off`

# 追記2 (2026-08-12): K2 の出力先を PopulationLog から checkpoints/weights.csv へ変えた

登録時の K2 は「PopulationLog に種ごとの重み平均・分散を追加」としていたが、
**出力先を変えた**。理由:

- PopulationLog は**毎ティック**記録する。観察したい系列は
  種(3) × モード(採餌/徘徊) × 場(9) × 統計(平均/SD) = **108 系列**あり、
  10万ティックでは 1,000万点を超える。進化の観察に必要な時間分解能は
  世代（≈数百ティック）であって1ティックではない
- PopulationLog の CSV は「個体数の時系列」という別の役割を既に持っており、
  列を108本足すと本来の用途で読めなくなる
- チェックポイント機構（既存）が同じ目的の器として既にある

実装:

| 出力 | 内容 | 粒度 |
|---|---|---|
| `checkpoints.csv` | 認知範囲 `cog_<species>_time` / `_space`（6列） | チェックポイント間隔 |
| `weights.csv`（新規） | 重み統計の**縦持ち**（condition, seed, tick, species, mode, field, count, mean, sd） | 同上 |

縦持ちにしたのは、横持ちだと列が100を超えて読めなくなるうえ、
場が増えるたびに列の並びが変わるため。集計側（pandas / Import-Csv）でも扱いやすい。

**徘徊時の重みも出す**ことが要点である。群れ重み (colonySelfWeight) は
徘徊時の重みにしか入らない（第4段 K4）ので、採餌側だけ記録していると
E1 の中心対象が観察できない。

PopulationLog は変更していない。

# 追記3 (2026-08-12): K1・K2 の実装完了と M 判定

E1/E2 の実験は未実施（変異パラメータの掃引は後日）。

## K1 の RNG 設計（決定論の要）

| 状態 | 消費 |
|---|---:|
| 変異が無効（rate=0 **または** sigma=0） | **0個** |
| 有効時、1成分あたり | **必ず3個**（抽選1 + Box-Muller 2） |
| 1出生あたり | **54個**（採餌9 + 徘徊9 = 18成分 × 3） |

- 抽選に落ちた成分でも3個引いて捨てる。「変異しない成分は引かない」に
  すると抽選結果で消費数が変わり、同じシードでも個体の履歴が違えば
  乱数列がずれる
- 逆に**無効時は1個も引かない**。引いて捨てると第4段との
  ContentHash 一致（M 判定の前提）が壊れる
- ガウス乱数は Box-Muller: `sqrt(-2 ln(1-u1)) × cos(2π u2)`。
  極座標法は棄却を伴い消費数が可変になるため不採用。
  `NextFloat01()` は [0,1) で **0 を返しうる**ので `1-u1` を取って
  `log(0)` を回避している。sin 側の2個目は捨てる
  （キャッシュすると ContentHash に含まれない隠れ状態になる）
- 挿入点は `TrySpawn`（facing を消費）の直後。prereg の「facing → 変異」の順序
- **重みに上下限は設けていない**（負＝自種を避ける、も探索対象。
  クリップすると分布の端が人工的に溜まり E2 の浮動観察が歪む）

## M 判定 — **合格**

48シード×3000ティック、`mutation`(rate=1.0 / sigma=0.1) と現行 `default` の比較:

| 指標 | default (4c) | mutation | 差 |
|---|---:|---:|---:|
| 草食獣 | 18.892 | 20.116 | +6.5% |
| 狼 | 4.416 | 3.783 | −14.3% |
| 餓死率 | 0.8066 | 0.7915 | −1.9% |
| 捕食率 | 0.8575 | 0.7244 | −15.5% |
| 出生 | 14.514 | 16.271 | +12.1% |
| ギルド絶滅 | 0/48 | 0/48 | — |
| 狼の全滅 | 1/48 | 3/48 | M5 の許容内 |

いずれも ±20% 以内で、M5 も両条件で合格。**sigma=0.1 は大きすぎない。**

## 変異が想定どおり働いていることの確認

`mutation` 条件、羊の `colony-sheep`（徘徊）、48シード平均:

| t | 平均（初期値 2.4） | SD |
|---|---:|---:|
| 1,000 | 2.3958 | 0.0359 |
| 2,000 | 2.4022 | 0.0677 |
| 3,000 | 2.4069 | 0.0947 |

**平均は動かず SD だけ単調に増える** — 期待値0のガウスノイズの理論どおりで、
E2（浮動）の予備観察にもなっている。`default` 条件では平均 2.400000・SD 0.000000。

## 2. 変異パラメータの掃引を省いた根拠

登録時は「`sigma × rate` の2次元をまず5シードで粗掃引し、
**浮動が観察でき、かつ即時絶滅しない**帯を特定してから確定する」としていた。
この掃引は**実施しない**。追記3 の M 判定が、その2条件を
`rate=1.0 / sigma=0.1` について既に満たしているためである。

| 掃引で確かめるはずだったこと | 追記3 で得られている値 |
|---|---|
| 即時絶滅しない | 48シード×3,000t で生態指標が全て ±20% 以内、ギルド絶滅 0/48、狼の全滅 3/48（M5 許容内） |
| 浮動が観察できる | 羊の `colony-sheep`（徘徊）の SD が 0.036 → 0.068 → 0.095 と単調増加。平均は 2.4 で不動（期待値0のガウスノイズの理論どおり） |

**掃引を回しても同じ点に戻ってくる**ので、形式的手続きになる。
ただしこれは「この値が最適」という主張ではない。
sigma を変えたときの応答は測っていないので、E1 の結果が
(b)「0 付近に留まる」だった場合、**それが真に勾配が無いのか
sigma が小さすぎて回廊まで到達しないだけなのかは、この1点では区別できない**。
その切り分けが必要になったら sigma の掃引を追加実験として登録する。

## 3. 狼を初期条件から外す

### 判断

E1・E2 は `wolfCap = 0` で走らせる。野生スポーンの狼枠を閉じると、
繁殖には既存個体が要るため**狼は一度も生まれない**。
「走行中ずっと不在」であって「途中で減る」ではない。

### 根拠（longrun100 の実測、100×100 × 10万ティック × 540シード）

| 観測 | 値 |
|---|---|
| 平均個体数 | meanWolves **1.05** / meanWolvesPerTick **2.43** |
| 全滅 | **232/540（43.0%）**。ギルド 0 / 植物 0 で、消えるのは狼だけ |
| 死因 | 餓死 45.77 対 捕食 11.78（per 1000 ticks）。個体あたり 0.363 対 0.093 で**餓死が捕食の約3.9倍** |
| 場への痕跡 | colony-wolf の fieldMean 0.00044（sheep 0.0133 / pig 0.0121 の約1/30） |

2匹前後で推移する個体群は人口学的確率性のみで絶滅する。
E1 は10万ティック走らせるので、**狼を入れると43%のシードで
走行中に条件が変質する**。「狼がいる世界」と「途中から狼がいない世界」が
混ざった集団の重み平均を、進化の結果として読むことはできない。

### 却下した代替案

- **(b) 走行長の短縮**: 狼の絶滅時刻の分布が未確認で、どこまで縮めれば
  条件が保たれるか決められない。かつ回廊探索に必要な長さを削る恐れがある
- **(c) 生存シードのみの条件付き解析**: 生存バイアスが入る。
  狼が生き残ったシードは獲物が散らばったシード（追記1 の機構）であり、
  それは群れが弱いシードである。**E1 の測定対象そのものと相関した
  選抜**になるので、最も避けるべき形

### この変更が測定対象に与える制約 — **結果の読み方の限定**

群れの利益は少なくとも3経路ある:

1. **採餌効率**（コロニー場が餌場の記憶として働く）
2. **繁殖機会**（K3-K4 結合。近くに同種がいると繁殖確率が上がる）
3. **対捕食者**（希釈効果、警戒の共有、捕食者の探索面積の消費）

**狼を外すと3つ目が測定対象から外れる。**
したがって E1 が測るのは「**採餌・繁殖効率の側面だけで見たときに、
進化が群れの回廊に到達するか**」であって、「群れの利益」全体ではない。

この但し書きは結果の解釈に直接効く:

- E1 が **(a) 回廊到達** なら、「対捕食者の利益が無くても回廊に届く」という
  **強い**結論になる（利益を1つ差し引いた条件で到達したため）
- E1 が **(b) 0 付近に留まる** なら、それは「群れに進化的到達経路がない」の
  証明**ではない**。対捕食者の経路を外した条件での結果であり、
  狼を入れれば到達する可能性が残る。この場合は狼ありの追試を
  別途登録すること
- E1 が **(c) 過密絶滅への暴走** なら、捕食圧という上側の抑制が無い条件での
  暴走なので、系レベル淘汰の観察としては**過大に出ている**可能性がある

失われる情報量の見込みは小さい。longrun100 で捕食は餓死の約1/4しかなく
（個体あたり 0.093 対 0.363）、狼は主要な死因になっていない。
第4段 4c で確認された「群れが獲物場を集中させ捕食者の探索面積を消す」機構は、
**捕食者にとっての害**であって被食者にとっての利益の測定ではない。
とはいえ**見込みは測定ではない**ので、上の限定は結果の記述に必ず併記する。

### 機構

群れ重みが 0 だと草食獣が空間的に一様に散らばる。採食圧が全面に及んで
草が半減し（適性セルあたり 0.222 → 0.133）、個体あたり餓死率が 5.6倍になる。
繁殖には空腹が `breedHungerMax` 未満であることが要るので、
飢えた個体群では出生がほぼ止まる。

これは追記1 で `nutrient-off` について記録した機構（餌が乏しい世界では
群れが生じず、獲物が散らばって捕食者が回復する）の**逆方向からの確認**である。
そこでは「餌が乏しい → 群れない」を見た。ここでは「群れない → 餌が乏しくなる」を見た。
**群れと餌量は双方向に結合している。**

### 二次的な要因: 野生スポーンの上限との位置関係

100×100 の `animalSpawnCap` は 87（基準 20 × 適性セル 9,737 / 2,225）。

| 条件 | 草食獣 | cap 87 との関係 | 野生スポーン |
|---|---:|---|---|
| longrun100 | 125.7 | **上回る** | 停止 |
| e1-diag-flock | 128.1 | **上回る** | 停止 |
| e1-corridor | 86.2 | **わずかに下回る** | **常時作動** |

`SpawnAnimals` は冒頭で `AnimalCount >= animalSpawnCap` なら即 return するため、
個体数が cap を超えている条件では野生スポーンそのものが止まり、
個体群は出生だけで維持される。E1 は 86.2 対 87 という**紙一重の差**で
その反対側にいた。

したがって観測された現象には2つの読み方がある。**どちらも成り立つ:**

1. **生態の結果**: w=0 の世界は餌が乏しく、繁殖が成立しない。
   これは模型についての正当な発見であり、
   「回廊の外は、進化が働くための繁殖基盤そのものを欠く」という
   (b) より強い主張になりうる
2. **模型の副作用**: 野生スポーンが重みをパラメータ値へ**リセット**する仕様が、
   個体数が cap を下回る条件でのみ効いてくる。これは
   「外から個体が湧く」という模型の都合であって生態ではない

**この2つは現時点で分離できていない。** 分離しないまま E1 を
「回廊に到達しなかった」と記録してはならない。

## 6. 再開時の最初の一手

**「野生スポーンが個体の重みをどう決めるか」を確定させること。**
これは prereg の追記6 として書く。実装より先に決める。

現状は `SpawnAnimals` → `TrySpawn(kind, x, z, facing, p)` が
**パラメータの初期重みを個体へ写す**（第3段 J2 の実装）。
個体数が `animalSpawnCap` を下回る条件では、この経路が集団の大半を占め、
遺伝形質を継続的にリセットする。E1 のように
「初期値を集団の平衡から離した位置に置く」実験は、この仕様と原理的に噛み合わない。

判断すべき選択肢（いずれも prereg 事項）:

1. **野生スポーンを移民として扱う** — 湧いた個体は現存集団から重みを引く
   （平均、あるいは無作為な1個体のコピー）。
   「外から来た個体が土地の遺伝子を持っている」のは不自然だが、
   リセットは起きなくなる
2. **野生スポーンを止める** — `animalSpawnCap` を平衡個体数より下げ、
   個体群を出生だけで維持する。生態系の構成が変わるので
   第4段までの判定との比較可能性が切れる
3. **初期値を平衡の側に置く** — E1 の問い（回廊の外から始める）を
   「回廊の内から始めて出るか」に反転させる。問いが変わる

**決める前に要る測定は1本。** `e1-corridor` のまま `animalSpawnCap` だけを
下げた条件を48シード×30,000ティックで回し、出生の割合が
どこまで回復するかを見る（10分）。回復するなら選択肢2が最も副作用が小さい。
回復しないなら、w=0 の生態そのものが繁殖を支えられないということであり、
選択肢3（問いの反転）を検討することになる。

**この測定を行うまで E2 は走らせない。** E2 は E1 の浮動幅を与える対照であり、
E1 が測れていない状態では基準として機能しない。
