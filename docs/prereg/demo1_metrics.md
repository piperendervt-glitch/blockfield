# Demo 1 事前登録 — ハイトマップ地形生成＋チャンクメッシング

登録日: 2026-08-08 / 対象タグ: demo-1.x（完了時にフリーズ）
方針: デモ級の軽量ガードレール（demo0_metrics.md と同方針）。

## スコープ
- A: SimCore 地形生成（VoxelGrid / ハイトマップ / バイオーム2種）
- B: チャンクメッシング（可視面カリング）と TerrainField への置換
- C: エディタ内プレビュー、実機セッション1回

## メトリクス
- M1（地形の成立）: 山（周囲より明確に盛り上がった領域）と
  平地が1つの地形内に共存して見える。実機で目視判定
- M2（性能・記録のみ）: 50×50×最大16層の地形表示で72FPS維持
  （パネル読み）。参考記録として100×100も試す。Go/No-Go対象外
- M3（決定論）: 同一シードで2回生成した地形のハッシュが一致。
  EditModeテストで判定（実機不要）

## Go/No-Go
- Go条件: M1合格 かつ M3合格
- No-Go時: 原因を1行メモしてから対処（基準自体は変更しない）
