# Demo 4 事前登録 — 設置・破壊とイベントログ

登録日: 2026-08-08 / 対象タグ: demo-4.x
方針: デモ級の軽量ガードレール。roadmap.md Demo 4 に対応。

## スコープ
- F1: 出所属性4値（固定レイヤー原則のAPI強制）
- F2: イベントログ実書き込み＋リプレイ機構
- F3: 設置・破壊操作（レイ＋ハイライト、次Tick先頭適用）
- F4: 場フィードバック（植生場減衰、suitability再計算、
  チャンク限定再メッシュ）
- F5: エディタのイベント注入ボタン
- ブロック種の持ち替えUIは含まない

## メトリクス
- M1（操作の成立）: 実機でハイライトに対し設置・破壊が
  意図通り機能する（誤セルへの適用がない）
- M2（固定レイヤー）: プレイヤー設置ブロックが生態系の
  数百ティックで不変。EditModeテスト＋実機で設置後放置し確認
- M3（リプレイ決定論）: f(シード, イベントログ) — 同一シード＋
  同一イベント列のリプレイで ContentHash 一致。EditModeテスト
- M4（場フィードバック）: 植物を破壊すると植生場が下がり、
  周辺の再スポーン確率が下がる。ヘッドレステストで定量
- M5（性能・記録のみ): 設置・破壊時のヒッチ有無（体感）、
  チャンク再メッシュ時間ログ
