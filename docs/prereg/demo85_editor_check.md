# Demo 8.5 — エディタでの事前確認手順（草の表示）

実機に行く前に PC で「草の高さで場の値が読めるか」を目視する手順。
M5 の本判定は実機セッション（帰宅後）で行うが、
**表示が成立しているかどうかは PC だけで確認できる**。

## 前提
- Unity Editor で本プロジェクトを開く（CLI テストと同時実行は不可）
- メニュー `Tools > BlockField > Terrain Preview`

## 手順1: 草が高さ3段階で描かれているか

1. `Seed = 12345`、`50x50`、起伏スケール 24 のまま **Generate**
2. **Simulate 100 ticks** を **15回**押す（合計1,500ティック）
   - ロジスティック成長は立ち上がりが緩やかで、400ティックでは
     まだ濃いセルが1つも無い（実測: 400tで平均0.115、1,500tで0.246）
3. Scene ビューを**斜め45度**にする（右上ギズモの角をクリック）

**期待**: 地表に緑の直方体が生え、**高さが3種類**ある。

| 植生場の値 | 高さ（ブロック比） | 見え方 |
|---|---:|---|
| 0.8 以上 | 0.75 | 高い。明るい緑 |
| 0.5 〜 0.8 | 0.45 | 中くらい |
| 0.2 〜 0.5 | 0.20 | 低い。やや暗い緑 |
| 0.2 未満 | — | **描かれない**（地面が見える） |

**ちらつきは正常**。閾値付近のセルはティックごとに高さが変わる。
これは「値が閾値付近にある」という情報そのものであり、
ヒステリシスで隠していない（事前登録の方針）。

## 手順2: 場の値と高さが対応しているか（答え合わせ）

1. 手順1の状態から **「場を表示 (E1 / Demo 8)」にチェック**、
   `表示する場 = Vegetation`
2. 真上から見下ろす（右上ギズモの Y 軸）

**期待**: 緑のオーバーレイが濃い場所ほど、草が高い。
オーバーレイと草の**位置が一致**していること（ずれていたら座標系の不具合）。

## 手順3: 草が食べられて減るか

1. 「場を表示」を外し、斜め視点で動物（白＝羊 / ピンク＝豚）を探す
2. **Simulate 10 ticks** を数回押し、動物の周りの草を見る

**期待**: 動物が通った後のセルの草が**低くなる**か消える。
時間が経つと戻る（成長 0.028 に対し摂食は一口 0.5）。

**注意**: 1頭が1ティックに食べるのは0.2程度で、草の高さが1段階
下がるとは限らない。数ティック見続ける必要がある。

## 手順4: けもの道が草の高さで見えるか

1. **Simulate 100 ticks** をさらに10回（合計2,500ティック程度）
2. 真上から見下ろす

**期待**: 草の**低い帯**または**草の無い帯**が網状に走っている。
これは Demo 8 第3段の踏み荒らしが植生場を削った跡で、
草が場になったことで**通常表示のまま**見えるようになった。

`表示する場 = Trample`（茶）に切り替えて、帯の位置が一致するか確認する。

## 手順5: 個体数の読み方

パネルの表示が変わっている:

- `Grass: NNN` — **草の総量**（植生場の合計）。移行前の「植物の本数」ではない
- `Sheep` / `Pigs` / `Wolves` — 従来どおり

実機パネルでは `Tick: N  Grass: NNN  Animals: N  Wolves: N` と出る。
同じ内容が30秒ごとにログにも出る（CLAUDE.md の規約）。

## 実機セッションで判定すること（帰宅後）

- **M5**: 草の高さで場の値が読めるか（パススルー越しに3段階が区別できるか）
- **M6**: 場5枚＋草のメッシュで72FPSを維持できるか

**セッション前に必ず build_quest.ps1 → deploy.ps1 を実行する**（CLAUDE.md）。

## 表示の更新コストについて（実装メモ）

草のメッシュは**1秒に1回**まとめて組み直す（`GrassView`）。
場は 1Hz でしか動かないので毎フレーム組み直す必要がない。
セルごとに GameObject を作らず**1枚のメッシュ**にまとめており、
移行前に約155個あった植物の GameObject は0になった。

エディタプレビューだけは GameObject をセルごとに作っている
（Simulate を押したときだけ走るので、エディタ用途では十分軽い）。
