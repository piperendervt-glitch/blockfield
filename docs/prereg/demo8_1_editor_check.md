# Demo 8 第1段 — エディタでの事前確認手順

実機に行く前に PC で「場と生き物の位置が合っているか」を目視する手順。
実機セッションは1回5分・装着中は操作できないため、可視化の妥当性は
必ずここで確認してから実機へ行く。

## 前提
- Unity Editor で本プロジェクトを開く（CLI テストと同時実行は不可）
- メニュー `Tools > BlockField > Terrain Preview`

## 手順1: 植物と植生場の位置が一致するか

1. Terrain Preview を開く
2. `Seed = 12345`、`50x50`、起伏スケール 24 のまま **Generate**
3. **「場を表示 (E1 / Demo 8)」にチェック**、`表示する場 = Vegetation`
4. **Simulate 100 ticks** を4回押す（合計400ティック）
5. Scene ビューで真上から見下ろす（右上のギズモで Y 軸をクリック）

**期待**: 緑の四角い印が、緑の小さな立方体（草）と黄色い立方体（花）の
**真下に重なり**、その周囲へハローのように薄く広がっている。
印と植物が横にずれていたら座標系の不具合。

**スクリーンショットの撮り方**: Scene ビュー右上の「…」→ なければ
Windows の `Win + Shift + S` で範囲を切り取り。真上視点で植物1個と
その下の緑印が重なっていることが分かる倍率まで拡大する。

**ヘッドレスでの裏付け（実施済み）**: 植物セル上の植生場の平均は
全体平均の 6.5倍（箱庭）/ 5.3倍（部屋）、場の最大セルと最寄り植物の
距離は 0 セル。SimCore 側の対応は取れている。

## 手順2: 狼の軌跡に恐怖場が積もるか

1. 手順1の状態から `表示する場 = Fear` に切り替える
2. **Simulate 10 ticks** を数回押し、そのつど Scene ビューを見る
3. 灰色の細長い立方体（狼）を見つけ、その通り道を目で追う

**期待**: 狼がいた場所に赤い印が点き、狼が進むと後ろに赤が**線状に**残る。
時間が経つと薄くなる（減衰 0.03）。
狼が1匹もいない場合は `Simulate 100 ticks` を押して湧くのを待つ
（狼は低頻度でしか湧かず、絶滅もする）。

**注意**: 狼が絶滅していると恐怖場は空になる。
パネルの `Wolves:` が 0 なら Reset して別シードで試す。

## 手順3: 草食獣の分布と獲物場が一致するか

1. `表示する場 = Prey` に切り替える
2. 白（羊）・ピンク（豚）の立方体の位置と青い印を見比べる

**期待**: 青い印が草食獣の**足元とその周囲数セル**に広がっている。
獲物場は拡散4パス・減衰0.015 で L≈7.3セル届く設計なので、
1個体の周りに直径10セル程度のにじみができる。

## 手順4: 3種の動物が「形」で判別できるか（Demo 8 追加）

色は照明・場のオーバーレイ・飢餓表現と競合して識別子にならなかったため、
**上から見た輪郭**で区別できる形にした。色分けも維持している。

1. Generate → **Simulate 100 ticks** を数回押して動物を湧かせる
2. Scene ビューを**真上視点**にする（右上ギズモの Y 軸をクリック）
3. 動物が固まっている所まで拡大する（マウスホイール）

**期待する輪郭（上から見た形）**:

| 種 | 色 | 上から見た形 |
|---|---|---|
| Sheep | 白 | 中くらいの長方形。前方に小さな頭 |
| Pig | ピンク | **幅の広い**ずんぐりした長方形。前に短い鼻 |
| Wolf | 灰 | **細長い線**。前に頭と左右の耳、**後ろに尾が突き出す** |

狼は尾のぶん前後に長く、耳が左右にはみ出すので、真上からでも
羊・豚と輪郭が明確に違う。これが見分けられなければ形の設計をやり直す。

### 手順4b: 斜め視点で足と背の高さを確認

4本足を追加したので、横から見た背の高さでも区別できる。

1. Scene ビューのギズモの**角**（Y と X の間あたり）をクリックするか、
   右ドラッグで見下ろし45度くらいに回す
2. 動物を横から見る

**期待（実測値）**:

| 種 | 足の長さ | 足の太さ | 背丈 | 見た目 |
|---|---:|---:|---:|---|
| Sheep | 1.1cm | 1.4cm | 4.5cm | 太く短い足。もこもこ |
| Pig | 0.9cm | 1.2cm | 3.5cm | 最も低い。地面すれすれ |
| Wolf | 1.8cm | 1.0cm | 4.0cm | 細く長い足で**背が高い**。胴が浮いて見える |

**足の底が地表に接している**こと（浮いていない・埋まっていない）も確認する。
エンティティは表層セルの中心に置かれるため、ローカルで -0.5 ブロック
（-2.00cm）が地表になる。3種とも足底をここに合わせ、胴を足の長さぶん
持ち上げてある（計算で検証済み）。

足の太さは 4cm ブロックの 1/4（1cm）を下限にしている。狼の足はこの下限。
実機で細すぎて見えない場合はこの下限を上げる。

**色も同時に確認**: 白 / ピンク / 灰 の3色になっていること。
実機では診断モードに一度入ると全個体が白くなる退行があったが、
原因は飢餓の色分けが解除時に `_BaseColor` を白で上書きしていたこと。
プロパティブロックごと外すよう修正した（種の色は乗算で残す）。

## スクリーンショットの撮り方
1. Scene ビューを真上視点にする（右上のギズモで Y 軸をクリック）
2. 動物が3種そろっている場所まで拡大
3. `Win + Shift + S` → 範囲選択でその領域を切り取り
4. 場の確認をするときは、同じ視点のまま「場を表示」を ON/OFF して2枚撮ると
   ずれの有無が比べやすい

## 実機で見るときの操作（参考）
- 右手B: 通常 ⇄ 診断モード
- 診断モード中に**左手Y**: マーカー → 植生(緑) → 恐怖(赤) → 獲物(青) → 非表示 を巡回
  - 「マーカー」は積もり面の色分け。**場と同時には出ない**
    （緑どうしが混ざって場が読めなくなるため）
- 診断モードでは狼が**1.6倍に拡大**され、直近40ティックの軌跡が
  白〜オレンジの印で表示される（新しいほど白い）

## 今回直した表示の不具合（実機で判定不能だった原因）

| 症状 | 原因 | 修正 |
|---|---|---|
| 場が植物・動物と一致しない | オーバーレイを**観測面の worldY** に描いていた。その上に積もった雪地形1〜4ブロックぶん下にずれ、地表に立つ生き物と合わなかった（実測: 観測面 0.01m に対し実際の地表は 0.080m） | ワールドの表層高さ (`GetSurfaceHeight`) に敷くよう変更。エンティティと同じ規約に統一 |
| 「非表示」でも緑の枠が残る | 積もり面マーカー（緑）が場と**同時に**出ていた | マーカーを巡回の1状態にし、場を見るときは必ず消えるようにした |
| 狼が見えず因果が追えない | 場の最終状態だけでは「なぜここが赤いか」が分からない | 診断モードで狼を1.6倍に拡大＋直近40ティックの軌跡を表示 |
| 通常モードで全個体が白い | 飢餓の色分けを解除するとき `_BaseColor` に**白を書き込んで**いた。マテリアルの種の色を上書きしてしまう。診断モードに一度入ると以後ずっと白 | 解除時はプロパティブロックごと外す。適用時も種の色に**乗算**する |
| 種が判別できない | 色だけに頼っていた。診断モード中は飢餓の色分けと場のオーバーレイに埋もれる | 上から見た輪郭で3種を区別できる形にした（EntityShape）。色分けは併用 |
| 「非表示」でも緑の枠が残る（再発） | マーカーの作り直しで**古い GameObject を捨てていなかった**（メッシュだけ捨てていた） | 作り直し時に GameObject ごと破棄。オーバーレイも非表示時にメッシュを空にする |

軌跡の実装方式は事前登録の**案A（直近Nティックの deposit 位置に短寿命マーカー）**を
選んだ。恐怖場の deposit 位置＝狼の位置なので案C（軌跡を線で描く）と同じものになり、
位置履歴を表示側で持つだけで済む。案B（最後に書かれてからの経過ティックを色相化）は
場と同じ大きさの配列を毎ティック更新する必要があり重い。
