# Demo 4.5b 事前登録 — VRモード（公開・録画用）

登録日: 2026-08-09 / 対象タグ: demo-4.5b.x
方針: 見せ方のタスク。生態系・地形の正しさとは独立しており、
Go条件は「公開映像として成立するか」の主観判定を含む。

## スコープ
- V1: パススルー無効化（PassthroughController の既存APIを使用）
- V2: 部屋のボクセル化（壁・天井・床下をブロックで表現）
- V3: モード切替（MR ⇄ VR をコントローラ操作で）
- V4: 見た目の調整（背景色、部屋ブロックの配色）

## メトリクス
- M1（VRモード成立）: パススルーが消え、現実映像が一切
  映らないことを実機で確認
- M2（部屋の再現）: 壁・天井・床がブロックで表現され、
  実際の部屋の形状が認識できる
- M3（世界観の統一）: 地形・生態系・部屋が同じボクセル表現で
  統一され、公開映像として成立する（主観判定）
- M4（モード切替）: MR ⇄ VR が実機で切り替わり、
  切替後も地形・生態系の位置がずれない
- M5（性能・記録のみ）: VRモードで72FPS維持

## Go/No-Go
- Go条件: M1 かつ M2 かつ M4
- M3 は主観判定のため記録のみ（見た目の調整は反復で行う）
