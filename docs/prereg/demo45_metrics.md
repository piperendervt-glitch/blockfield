# Demo 4.5 事前登録 — Room Terrain（部屋が箱庭になる）

登録日: 2026-08-09 / 対象タグ: demo-4.5.x
方針: デモ級の軽量ガードレール。roadmap.md Demo 4.5 に対応。
前提実測（demo3 M7）: グローバルメッシュ単一・16k頂点・
部屋バウンズ約4.5×2.1×4.2m・座標変換不要。

## スコープ
- G1: シーンモデル取得（ARMeshManager 恒久化＋ARPlaneManager
  ラベル）と観測イベント記録
- G2: 多層ハイトマップ化（XZグリッド上→下レイキャスト、
  複数ヒット=床と机上等の各面）
- G3: 雪積もり地形合成（各ヒット面に1〜4層の薄い起伏地形）
- G4: 壁の Boundary 化（通行不可セル、origin=Reality）
- G5: 平面ラベル→バイオーム（床=平原/机=丘陵/棚=山岳）
- G6: 分散生成（1〜3分許容、フレーム分散）
- G7: 既存生態系の部屋スケール動作（スポーン・徘徊・捕食が
  多層地形上で機能）

## メトリクス
- M1（多層積もり）: 床と机上の両方に地形が積もることを実機で
  目視確認
- M2（Boundary）: 動物が壁を越えない（壁際で向き変更する）
  ことを実機観察またはヘッドレステストで確認
- M3（バイオーム対応）: 床と机上で異なるバイオーム（地形の
  起伏傾向）が確認できる
- M4（決定論）: 同一の観測データから同一 ContentHash。
  EditModeテスト（記録済み観測データのリプレイで検証）
- M5（生成時間・記録のみ）: スキャン完了→地形表示まで3分以内
- M6（性能・記録のみ）: 部屋スケールで 72FPS 維持
- M7（生態系動作）: 部屋スケールでスポーン・捕食が引き続き
  機能（パネル累計で確認）

## Go/No-Go
- Go条件: M1 かつ M2 かつ M3 かつ M4
- No-Go時: 原因を1行メモしてから対処（基準は変更しない）
