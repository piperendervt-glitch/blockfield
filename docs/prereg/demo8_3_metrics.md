# Demo 8 第3段 事前登録 — 踏み荒らしと進化の基盤

登録日: 2026-08-09 / 対象タグ: demo-8.3.x
方針: roadmap Demo 8 第3段。動物の通行が植生を減らす痕跡を導入し、
死の場（草が茂る）と対になる循環を作る。あわせて、将来の
進化的アルゴリズムに向けて行動の重み付けを個体が持つ構造に移す
（進化本体は実装しない）。

## スコープ変更の記録
第3段は当初「踏み荒らし＋コロニー場」の予定だったが、両者は
対の関係になく独立した機構であるため、「一度に1段」の原則に
従い踏み荒らし単独とする。コロニー場は第4段に繰り下げ、
踏み固めは第5段とする。

## スコープ
- J1: TrampleField（動物の通行で植生場を下げる、τ中）
- J2: 進化の基盤 — 行動の重み付けを SimParams から Entity へ移管
  （進化本体＝繁殖時の継承と変異は実装しない）
- J3: 可視化と指標
- J4: 判定

## メトリクス
- M1（けもの道の可視化）: 動物の通行が多い経路で植物が減り、
  通常モード（診断モードでなく）で草の生えない筋として
  視認できる。実機目視
- M2（踏み荒らしの定量）: 踏み荒らし場が高いセルの植物密度が
  低いセルより有意に低い。48シードで定量（対照 = trample効果0）
- M3（死の場との循環）: 踏み荒らし場と死の場が空間的に
  分離するか、あるいは重なるかを記録（予測: 通行の多い場所と
  死ぬ場所は必ずしも一致しないため分離するはず。
  記録項目であり Go 条件に含めない）
- M4（決定論）: ContentHash 一致（踏み荒らし場と Entity の
  重みを含む）
- M5（生態系の安定）: Demo 8 第2段で確立した基準
  （草食獣ギルド≧1 かつ 狼≧1 かつ 植物≧1、時間を通した最小値）
  を48シードで維持
- M6（進化基盤の等価性）: 重みを Entity に移管しても挙動が
  変わらない。移管前後で同一シードの ContentHash が一致するか、
  一致しない場合は個体数推移が統計的に同等であることを48シードで確認
- M7（性能・記録のみ）: 場5枚で72FPS維持

## Go/No-Go
- Go条件: M1 かつ M2 かつ M4 かつ M5 かつ M6
- M3、M7 は記録項目
