# Demo 3 事前登録 — 捕食・繁殖と植生場（場を動的にする）

登録日: 2026-08-08 / 対象タグ: demo-3.x
方針: デモ級の軽量ガードレール。roadmap.md Demo 3 に対応。
生態系バランスの良否は問わない（demo2 同様、バランスは Demo 5）。

## スコープ
- E0: 視認性改善（エンティティ面明度差＋地形頂点AO）
- E1: 植生場（τ小）— 拡散・減衰・植物による書き込み・
  閾値スポーン（場が繁殖の主体）
- E2: 草食獣の摂食（植生場勾配の場読み＋空腹状態）
- E3: 肉食獣（狼、視界内追跡）
- E4: 番・繁殖（個体ベース）
- E5: 個体数CSVログ＋イベントログ基盤の枠
- E6: 偵察コード（ARMeshManager メッシュ取得検証ログ）
- E7: Runtime 表示（狼モデル、摂食・繁殖の見た目反映）

## メトリクス
- M1（捕食の成立）: 草食獣が植物を食べ植物数が減る場面、
  狼が草食獣を捕食する場面を実機で目視確認
- M2（繁殖の成立）: 出生による個体数増加を実機パネルの
  数値または目視で確認
- M3（決定論の維持）: 同一シード＋同一ティック数で
  ContentHash 一致（植生場を含む）。EditModeテスト
- M4（場の効果）: 植物分布が一様ランダムでなく偏る
  （既存植物の周囲に新しい植物が生えるクラスタ化）。
  ヘッドレステストで定量（例: 新規スポーンの過半が既存植物の
  近傍3セル以内）＋エディタ目視
- M5（視認性・記録のみ）: AO＋エンティティ明度差の主観メモ
- M6（性能・記録のみ）: 72FPS維持、シムティック処理時間
- M7（偵察・記録のみ）: グローバルメッシュの頂点数・
  バウンディングボックス・座標系のログ取得
