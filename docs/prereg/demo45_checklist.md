## 操作
| 入力 | 動作 |
|---|---|
| 右手 **B** | 部屋地形の表示モード切替（0 通常 ⇄ 1 診断） |
| 右手 A | 積もり方のシード巡回（地形と生態系が作り直される） |
| 右手 トリガー / グリップ | 設置 / 破壊（Demo 4） |

箱庭地形（原点上の 50x50 のブロック平原）は **G7 で廃止**。
生態系は部屋地形の上で動く。左手Xのトグルも無くなった。

## パネルの読み方（Demo 4.5 で追加した2行）
```
Room[B]: 0 NORMAL   Surf: 9073 (avg 1.87)
Dist1/2/3+: 1744/2001/1109   Snow: 9500 (120ms)
```
- `Room[B]` — 現在のモード（`-` = まだ合成前）
- `Surf` — 検出した積もり面の総数と1セルあたり平均
- `Dist1/2/3+` — 1面/2面/3面以上のセル数
- `Snow` — 積もったブロック数と合成時間

## 診断モード（B を1回押す）の色
- **緑の平板** = 採用した最上面（ここに積もらせた）
- **青の平板** = 2面目以降（積もらせなかった）
- **黄の平板** = 通行不可セル（G4 の壁。積もらせず Stone を積む）
- **枠の色** = 平面ラベル
  - 白 = Floor / 橙 = Table / 紫 = Other / **赤 = Unknown** / シアン = Couch
  - 黒が見えたら異常（Ceiling/WallFace は除外済みのはず）

### 各項目の補足
- **M2**: 壁面（WallFace 平面）には隙間が残るが、外周 Boundary で漏れは
  防げている。実測 (81x67): 平面由来588セル＋外周123セル＝711セル。
  外周の追加が123セルで済んだのは、平面由来の壁が外周の大半を既に
  覆っていたため。
- **M3**: ユーザーメモ「床が散らかっているため差は明瞭ではないが判別可能」。
  Unknown（小物・荷物の上面）が床面に混じるため、床の一部が丘陵/山岳に
  なることが原因。仕様どおりの挙動である。
- **M5**: 第4回セッション実測 — スキャン16ms（16,088頂点・32,544三角形）、
  ハイトマップ構築74ms（81x67）、地形生成＋メッシュ化68ms（11,262ブロック・
  74チャンク）。合計 0.16 秒で、基準の3分を大幅に下回る。
- **M6**: **ログに出力していなかったため転記できない**。FPS は DebugPanel の
  画面表示のみで、logcat には出ていない。第5回以降で取得できるよう
  DebugPanel に定期ログを追加した（本コミット）。
  間接的な証拠として、population.csv の60秒間隔保存が
  15:18:28 → 15:19:28 とほぼ正確な間隔で記録されており、
  シムティックの駆動は計画どおり進んでいた。
- **M7**: 第4回セッションの適性場分布（実測）—
  床帯 2141/2632 / 机帯 1275/1362 / 棚帯 1115/1248
  （適性>0 のセル数 / 面のあるセル数）。3帯すべてに湧ける場所がある。

### 次への課題（Demo 5 の入力）
- **部屋スケール（5,427セル）は箱庭（2,500セル）の2倍以上**のため、
  同じスポーン確率だと植物密度が薄く、餓死が多い。
  Demo 5 の密度基準の正規化（セル数に対する比率で定義し直す）の入力とする。

### 途中経緯（設計判断の記録）
1. **過検出**: 法線Y成分を絶対値で判定していたため天井まで積もり面に
   なっていた（平均3.67面/セル）。実測ログで発見し符号あり判定へ修正
   （1.87面/セル）。除外の56%が法線条件で、符号あり/絶対値=49% という
   計測から巻き順が正しいことも確定した。
2. **Unknown ラベル**: 診断表示（赤枠）で正体を目視確認。布団の上・
   ペットボトル・コップ・棚の小物・散らかった荷物の上面であり、
   ARPlaneManager が平面化しない現実の物体だった。雪積もりとしては
   正しい挙動なので採用を維持した。
3. **位置ずれ**: 部屋地形をワールド直置きしていたため、HMD の再装着に
   伴う再ローカライズでずれた。観測**と同じ瞬間**のアンカーポーズで
   換算してアンカーの子にする剛体親子付けに変更し、着脱2回＋視点リセットでも
   位置が保たれることを確認した。グリッド軸は部屋の向きのまま保っている。
4. **壁の切れ目**: WallFace 平面が4枚しかなく窓・ドア・家具の陰で
   切れ目が生じた。観測グリッドの最外周を無条件 Boundary にして塞いだ。
