# 理論ノート — 設計判断の理論的基盤

roadmap.md から参照される思想・理論の記録。2026-08-11、
帰省移動中の議論より。設計判断に直結するものは roadmap 本体に
あり、本ノートはその背景と、プロジェクト間を貫く一般原理を残す。

## 1. LLMマルチエージェント失敗の教訓(レジーム誤配置)

NCA-LLMリング(v1〜v6)、AAS、スティグマジー的LLM協調の失敗は、
レジーム誤配置として統一的に説明できる。

LLM間のプロンプト通信は「場」の成立要件を全て欠く:
- 合算可能性がない(テキストは加算できず、連結は平均化でなく
  肥大化。誤りが希釈されず増幅される)
- 減衰・拡散が定義できない(τによる忘却がない。要約は非線形で
  制御不能、かつそれ自体が誤りの注入点)
- 副産物通信でない(発話は全力の生成で、読み手のコンテキスト
  ウィンドウという最高価の資源を専有する)
- 書き手と読み手の独立性が壊れる(ミラー効果、集団思考、迎合 —
  NCA-LLM で実測済み。物理の場では起きない意味空間特有の汚染)

一般原理: LLMは純粋な高次元内部レジームの装置であり、協調・
調整・集約は低次元レジーム(スカラー場、決定論的ゲート)の仕事。
高次元装置同士を直結してはならず、間に低帯域の公共チャネルを挟む。
生物も脳と脳を直結せず、遠吠え・匂いという低次元信号を挟む。

成功例は全てこの型に従う:
- multimodal-aas-bird: consensus-agreement gate(決定論的スカラー
  機構)が重み更新を担い、Cohen's d=4.014
- LYSA: 定型ノードを決定論的ハーネスに置換、LLMは端点のみ
- TRUSS: 合議でなく constitution.md(環境に置かれた場)と役割分離
- blockfield: エージェント間通信ゼロ、全て場経由

LLMの配置原理: 書き込み側はスカラーへの射影を挟む(場に書ける
のは射影だけ、テキスト本体は環境に置く)。読み出し側は場の勾配が
閾値を超えた時のみ起動(注意のゲーティング)。調停は決定論的な
集約で行う。

## 2. ハードウェア降下の階段(個体の計算下限)

生態的知性の個体に必要な計算は極小: 場を読む(近傍5値)、勾配を
選ぶ(乗算7回・比較4回)、動く、書く(加算1回)。固定小数点8bit、
数十バイト、1Hzで足りる。

降下の5段:
- 段1: Raspberry Pi Pico級(数百円) — 4〜5桁の過剰性能。真の用途は
  個体でなく場のセルを担うインフラ(pico-mesh は既にこの実証)
- 段2: 8bitマイコン級・ATtiny(数十円) — 勾配追従+deposit は余裕。
  乾電池で年単位。「愚かな個体を数百体」の経済が成立
- 段3: アナログ回路(トランジスタ数個) — Braitenberg 車両: 光センサ
  2個をモーター2個に交差配線するだけで走性が実現。勾配比較を
  差動回路の物理が行う。デジタル計算ゼロ(BEAM ロボティクスが
  1990年代に実証済み)
- 段4: 物理そのもの(計算素子ゼロ) — Capillary Rheostat と
  rill-network の段。流路抵抗=重み、流量=行動、蒸発=τ。
  ember-network の PTC(温度履歴が抵抗に蓄積)も同段の素子
- 段5: 個体の消滅 — Demo 14 の水滴。個体概念なしのスティグマジー

真のボトルネックは個体でなく場の実装。3形態:
- (a) 環境インフラ型: セルノード格子(Pico級)が場を保持、個体は
  通りすがりに近距離通信で読み書き。pico-mesh が原型
- (b) 物理媒質型: 場を本物の物理量にする(蓄光塗料は書き込み+
  自然減衰τを無料実装、匂い、湿り、温度)。拡散・減衰を物理が
  無料計算。制約はτの設計自由度が媒質に縛られること
- (c) 個体分散型: 個体が地図断片を保持し同期 — 個体の要求が
  跳ね上がり「個体を愚かに保つ」思想と矛盾する罠。採らない

設計原理: 個体は段2〜4まで愚かにし、賢さの残余は(a)か(b)に置く。
蟻の答えと同じ(蟻は愚か、フェロモンと大地が場を担う)。

最小実証の部品表(段階3の橋渡し実験、総額数千円):
- 場: pico-mesh 拡張(セルノード格子、BLE ビーコンで値を広告)
- 個体: ATtiny+モーター+受信回路の走性マシン数台(1台数百円)
- 課題: 未訪問度の場による巡回(個体は「ビーコン値の高い方へ
  曲がる」だけ、通過でノード値をリセット)
- 測定: blockfield と同じ流儀(カバレッジ時間曲線、ノード故障時の
  劣化、個体追加時のスケール)
- blockfield のシミュレーションがこの物理系のデジタルツイン
  (事前検証装置)になる

## 3. 評価軸の宣言(生態的知性の測り方)

本プロジェクトが作るのは個的知性(AI)ではなく生態的知性である。
- 個的知性: 知能の容れ物が1個(モデルの重み)。精度・能力で測る。
  大きくするほど賢く高価(スケーリング則)。能力が1点に集中する
  ため制御が難しい
- 生態的知性: 知性の所在が特定できない(個体と場の循環にのみ
  現れる)。評価軸は頑健性・追従性・維持費。広くするほど賢く
  単価は変わらない(場の更新はセル数線形、個体は愚かなまま)。
  能力が系に薄く分散し、読める・消せる・部分停止できる

Demo 8.5 の「全個体数域で場方式が速い」は、この異なるスケール
経済の最初の実測点。

RC+AAS との接続: 「制御不能な AI を抑止する」という研究目的に
対し、抑止する側のシステムは生態型で作る(個の超知能に個の
超知能をぶつけない)。deliberate smallness、substrate-dependence、
controllability という設計原則は、生態的知性の側に立つ選択である。

## 4. 場の階層構造と0次元場としての個体状態(2026-08-11 追記)

第4段の設計調査で「breedCooldown・hunger は場に移せない
(個体固有の履歴であり、主語を場所に替えると機能が消える)」
ことが確定した。これは移送限界の2例目(1例目は第7段で予測済みの
hunger)。

判定質問の確立: 押し付け候補の事前判定は「主語を個体から場所に
替えても機能が保たれるか」。獲物場・恐怖場・踏み荒らし場は保たれた
(密度・危険・頻度は場所の性質)。hunger・breedCooldown は保たれない
(生理的履歴は個体の性質)。生物も同じ線を引いている(フェロモンは
外部化したが、ホルモン・疲労は38億年外部化していない)。

再解釈: 個体の状態変数は「0次元に縮退した個体内の場」と読める。
hunger / breedCooldown は deposit(事象が書く)・τ(線形減衰)・
読み出し(閾値判定)というワールド場と同一の文法に従い、唯一
「拡散」だけを欠く(0次元には近傍がないため)。拡散の消失=私的で
あること。移送の限界は「0次元場は拡散を持たずワールド場と合算
できない」という場の幾何からも導ける。

一般化: 現実の低次元レジームは一枚の場ではなく、膜で仕切られ
変換器で接続された場の階層である(細胞内カルシウム場 → 体内
ホルモン場 → 個体群フェロモン場 → 生態系の土壌・植生場。
各層が固有の空間・媒質・τを持つ)。層間は専用の変換器(分泌腺、
感覚器)でのみ接続される。

設計方針: 現段階では個体内場を0次元のまま扱う(実装変更なし、
「個体の単純化の限界を測る」という現行の問いを濁さないため)。
個体内場の次元を上げるフェーズ(体の部位ごとの状態、触覚の空間
分布)は将来に予約し、その際は ember-network(基板上の温度場=
物理的な個体内2次元場)、fiberfeel-rig(触覚場)との接続点になる。

### 移送限界の3例目: 同時性(瞬間の相関) — 2026-08-12 追記

第4段 4b で「隣に相手がいるか」(FindBreedPartner)を場に移そうとして
**実測で破綻した**。これまでの2例(hunger・breedCooldown)は実装前の
判定質問ですり抜けを防げたが、これは**事前予測をすり抜けた初の例**である。

なぜすり抜けたか: 主語変換テストは通ってしまう。「相手が隣にいる」の
主語を場所に替えると「その場所に同種が居る」となり、一見成立する。
しかし場は**時間積分**であり、元の判定が要求していたのは**同時性**
(同じティックに二個体が隣接していること)だった。積分は瞬間の相関を
落とす。1頭が滞在するだけで痕跡は積もるので、**単独個体が自分の
残した痕跡を読んで「相手がいる」と誤認する**。

実測(48シード×3000ティック):
- 旧判定が成立するのは全評価の 0.32% (同時性は稀な事象)
- 閾値 0.02〜0.05(滞在の下地の層)では評価の 14〜56% が通り、
  草食ギルドが 46〜47/48 シードで絶滅。数が少なく散らばっている
  狼ほど隣接要求が強い歯止めだったため、外れた途端 4.95 → 29 に暴走
- 閾値 0.2 以上では出生 deposit に支えられたセルだけが超えるため
  双安定になる(繁殖ゼロのシードが 26〜35/48、平均は暴走シードの混合)
- 従来の繁殖頻度を再現する閾値は**存在しない**

判定質問の改訂: 主語変換に加えて**「元の判定は瞬間の状態を見ているか、
それとも履歴を見ているか」**を問う。瞬間の相関(同時性)を要求する判定は
場に移せない。密度・危険・頻度が移せたのは、いずれも履歴の統計として
意味を持つ量だったからである。

回避策(4b で採用): 可否のゲート(0/1)ではなく**確率の変調**にする。
場の濃さを繁殖確率に掛けると、同時性は「濃い場所ほど相手が居やすい」
という確率的な対応に緩められ、単独個体の自己痕跡でも確率が十分低く
保たれる。同時性そのものは復元できないが、集団の統計としては整合する。
場に移せない量でも、**0/1 の判定を確率の変調に落とせば橋がかかる**
ことがある、というのが本例の一般的な教訓である。

### 場を共有する機構は独立に調整できない — 2026-08-12 追記

第4段 4c(群れ行動)で、**同じ場を読む2つの機構は独立な変数ではない**ことが
実測で分かった。コロニー場は 4b で繁殖確率を決め(K3)、4c で移動先を決める(K4)。
両者を結ぶのは場そのものである:

  群れる → その場所の場が濃くなる → 繁殖確率が上がる → 個体が増える
  → さらに濃くなる

4b で決めた繁殖の定数は「群れが無いときの場の分布」を前提にしていたので、
群れを入れた瞬間に前提が崩れた。実測では出生が6倍に暴走し、
草食ギルドが 2〜10/48 のシードで全滅した。片方(繁殖の定数)を取り直すと
**群れは残ったまま崩壊だけが消える**ことから、崩壊の原因が群れ行動ではなく
機構間の結合であることを分離できた。

含意: SBCE の「変数を1つずつ変える」は**変数が独立であること**を前提にしている。
場を介した設計では、新しい読み手を足すことが既に調整済みの読み手の
前提を壊しうる。段階を分けるときは「この段で足す読み手は、
既存の読み手が見ている量を変えるか」を先に問うこと。
変えるなら、その段の掃引は既存パラメータの再掃引を含む。

これは生物の側でも同じ構造を持つ。1つのフェロモンが複数の行動
(採餌・繁殖・集合)を制御している場合、片方の感受性だけを進化させることは
できず、必ず他方も引きずられる。**場の共有は機能の結合を強制する** —
分離したい機能には別の場(別の化学種)が要る、という設計上の含意になる。
第4.5段で進化を回すとき、この結合は「進化が別の場を要求するか」という
問いとして再登場するはずである。
