魚の段が落ちる、Phase D の判別）」の実施状況を問われ、`docs/design/roadmap.md`
を検索して**いずれも記録が無い**ことを確認した。
「単独ではやらず v14 の再構成カードに吸収する」との指示に従い、手を付けていない。

なお C-009 と C-011 で roadmap に追記した箇所があるが、いずれも
**系列2 の停止の記録ではない**（横断原則／系列1 再開手順／L0 の設計と負債）ので、
C-012 の範囲とは重ならないと判断している。重なると判断された場合は指示を待つ。

## 取りこぼした指示の記録

同じ型を繰り返さないために、取りこぼした指示そのものを残す。

| 取りこぼし | いつ気づいたか | 対処 |
|---|---|---|
| 起動直後パネルへのシーン名・ブランチ名・HEAD の表示 | 依頼の次の回で再指示されて | C-006 で実施（`BuildStamp`） |
| 刻印をログにも出す（パネルのみだった） | 実機セッション後の突き合わせで | C-008 で実施し、`AquariumPanelLogParityTests` で固定 |
| `build_quest.ps1` の `-Aquarium` 付け忘れ（指示ではなく手順の取りこぼし） | 実機で生態系が起動して | C-006 で引数必須化 |
| （4件目。ユーザー申告による。当方では特定できていない） | — | 台帳の新設そのものが対処 |

**4件目が特定できていない。** 心当たりを推測で書くと台帳が当てにならなくなるので、
空欄のままにしてある。判明したら追記する。
