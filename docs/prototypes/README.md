## flow/ — 回流 × 群体（否定的結果）

**問い**: 「群体が選ばれない」原因は推進への淘汰圧の不在か。
流れを入れれば link 遺伝子は選択されるか。

**実行**:
```
python3 experiment.py     # M-F1 / M-F2 / M-F3
python3 exp2.py           # M-F4
```

**事前宣言した判定と結果**:

| 判定 | 内容 | 結果 |
|---|---|---|
| M-F1 | 対照(U=0)で link が低位を維持 | **不合格** 対照 0.254（創始者 0.25 から動かず） |
| M-F2 | 流れ(U=0.35)で link 上昇 | **不合格・逆向き** d = −0.946、8シード中5で負 |
| M-F3 | 決定論 | 合格 |
| M-F4 | 剛性(体軸整列)が救済 | **不合格** d = +1.182 だが符号一貫 6/8 < 宣言 7/8 |

**最重要**: M-F1 の不合格により、このモデルは
ビューア版の「link が 0.03 まで刈られる」現象を再現していない。
したがって M-F2 の逆向きの結果は「流れ仮説の反証」としては読めない。
**検定台そのものが未検証**であり、結論の適用範囲はここに限定される。

**それでも得られた機構**: 流れのある世界では定位に方向の揃った遊泳が
要るが、独立の向きを持つ個体の集まりはベクトル平均で相殺される。
実際のクダクラゲの泳鐘が共通体軸に整列しているのはこの制約への解答。
flexible+流れ 0.183 / rigid+流れ 0.270 / rigid+静水 0.218 という並びは
剛性と流れの**交互作用**を示唆する。

**仮説の置き換え**: 「流れを入れれば群体が選ばれる」→
**「剛性は群体成立の前提条件であり、流れは剛性がある場合にのみ
利益に転じる」**。C# では **2×2 要因計画（flow × rigid、48シード）**
として事前登録する。

**設計してよかったもの / いけなかったもの**: 世界法則（流れ U、
餌の湧きと減衰、推力 ∝ n、抗力係数 ∝ n^(2/3)）は設計。
個体の戦略パラメータ（link、拍動周期）は遺伝子と変異のみで、
一切ハンドチューニングしていない。

**開発中に判明した落とし穴**（C# 実装で繰り返さないこと）:
- 餌の場に減衰項がないと全域が飽和し、「そもそも死ぬ理由がない」
  世界になる。link は中立浮動しかしない
- 個体の向きを純粋なランダムウォークにすると、餌と運動の間に
  結合が存在せず、**仮説を検定できない世界**になる。
  klinokinesis（条件依存の旋回率）が必須

## jelly/ — クラゲの神経-運動（興奮性媒質リング）

**問い**: クラゲの遊泳と操舵は、**方向を計算するコードを一切持たずに**、
興奮性媒質の伝播と減衰だけから成立するか。
判定の全文は `docs/prereg/jelly_1_metrics.md`。

**実行**:
```
python3 excitable_ring.py      # M-J1a / M-J1c
python3 reentry_map.py         # M-J1b（R₀ の境界）
python3 j2_attenuation.py      # M-J2b（g の符号反転）— 旧振幅モデル
python3 j2c_quantitative.py    # M-J2c 48シード       — 旧振幅モデル
python3 j2_wave_amplitude.py   # 波振幅モデル（正）+ J3a / J3b
python3 j2c_waveamp.py         # 波振幅モデルでの M-J2c と多重刺激の新旧比較
```
HTML 4本はブラウザで開く（自己完結）。

### 成立した機構

| 判定 | 結果 |
|---|---|
| M-J1a 伝播と対消滅 | 単一刺激が双方向に伝播し、**t=8 で対蹠（セル8）にて対消滅**。t=12 で消滅 |
| M-J1b リエントリー境界 | N=16 で **R₀=13 はリエントリー / R₀=14 で消滅**。理論式「一周 N ステップ > R₀ + 回復」と一致 |
| M-J1c 決定論 | ハッシュ `8328cc8b66b40f71` が二回一致 |
| M-J2b 逃避の向き | 16方位すべてで刺激と正反対（誤差 0.00°）。**g=1.00 では TOWARD（誤り）、g≤0.95 で AWAY** |
| M-J2c 定量（48シード） | 旧モデル 最大誤差 0.00° / 波振幅モデル 0.000°。g・drag の揺らぎに頑健 |
| M-J2d 重ね合わせ | **波振幅モデルのみ 225.0°**（ベクトル平均と厳密一致）。旧モデルは 158.5° |
| M-J3a 持続遊泳 | 単一ペースメーカーで移動距離 **23.6 / 47.7 / 107.3**（t=100/200/400）と線形。4方位すべて期待方向から誤差 1.8° 以内 |
| M-J3b 偏向と復帰 | 側方刺激で **360.0° → 315.1°**、刺激が消えると **360.0°** に復帰 |

### 設計上の要点（C# 実装で繰り返さないこと）

- **同期更新（ダブルバッファ）が必須。** インプレース更新は +index 方向への
  瞬時伝播という非対称を生み、1ティックで波が複数セル進む
- **振幅減衰 g は装飾ではなく操舵機構の構成要素。** 減衰が無い（g=1.00）と
  抗力との相互作用で「後発の側が勝つ」力学になり、**逃避の符号が反転する**
- **振幅は「波が運ぶ状態」であって幾何距離ではない。**
  刺激からのホップ数 `g^hops` を毎回計算する旧モデルは、単一刺激では
  正しく見えるが**多重刺激で破綻する**（158.5° 対 225.0°）。
  距離を計算するコードを書かないこと
- **操舵はペースメーカー位置で決まる。** heading 変数を持たない
- **不応期による痛覚信号のマスキングは創発現象**。実装せず、出てくるのを観察する

## homeostat/ — 生理層

**問い**: 部屋の CO₂ / 気圧の変化が、水槽の場を経由して
体内場（閾値 θ）にどう伝わり、ホメオスタシスとして働くか。

**実行**: ブラウザで開く（自己完結、外部依存なし、iPhone 可）。
`結合を切る` ボタンが M-H3 のアブレーション。

**判定結果**:

| 判定 | 結果 |
|---|---|
| M-H3 アブレーション | **成立**。結合ONで拍動率 0.849倍、OFFで正確に 1.000倍 |
| 適応性 | **結合ONの方が生存が多い（39/64 vs 30/64）**。代謝抑制は適応的 |
| 設定点の不在 | 0.849 という平衡値はコード中に存在せず、酸性度→θ と空腹→駆動の釣り合いで決まる（settling point） |
| 回復の非対称性 | 表層は数分で平衡、深層は長時間酸を保持。「入るのは速く、抜けるのは遅い」 |

**棄却した仮説2件**（当初の説明文は誤りだった）:
- 「酸性層からの逃避による再分布」— 6シードで d = −0.346、
  符号一貫 4/6。有意でなく、わずかに逆向き
- 「換気後のオーバーシュート」— 機構自体が存在しなかった。
  空腹→駆動を追加しても、深層が酸を抱え続けるため回復が起きない

**発見: 受容器は速度でなく旋回率に接続しなければならない**

再分布が起きなかった理由は、θ が遊泳速度を支配するため
**動きが遅い場所ほど密度が上がる**（走化性で既知の性質）。
pH 受容器から旋回率への独立経路を1行足して再検定した結果:

| 判定 | 結果 |
|---|---|
| M-K1 経路追加で酸から離れる | **合格** 平均深度 0.492 → 0.512、paired d = +0.978、符号一貫 5/6 |
| M-K2 生存を損なわない | **合格** 41.7 → 42.0 |
| 用量反応 | **単調**。係数 0 / .006 / .012 / .024 / .048 / .096 に対し深度 0.492 / 0.510 / 0.512 / 0.553 / 0.586 / 0.664 |
| 最適値の存在 | 生存は 0.024 超で低下（42.0 → 39.7 → 38.8 → 31.7）。曲がりすぎると餌場にも留まれない |

方向を計算するコードの不在は grep で確認済み
（勾配・atan2・符号判定いずれも0件）。

**jelly_2 prereg に載せる3点**:
1. 旋回率経路の必須性
2. **結合係数（現状 0.012）を手で置かず遺伝子化する** — 最適値が存在するため
3. 旋回コスト（非対称収縮は前進推力を食う）は jelly_side の
   噴流係数の実測から後で導入する。**順序を逆にしない**

**本模型の限界**: 気圧シナリオの予測型／反応型は進化させたのではなく
固定戦略として置いたもので、単一シードのため予測型の優位（0.039、
対照 −0.001）は示唆どまり。48シードでの検証は C# 実装側の仕事。

**記述レベルの混在（既知の問題）**: 「酸性度→θ」は生物物理的
（表面電荷の遮蔽、細孔のプロトン阻害、ギャップ結合の閉鎖）だが、
「空腹→駆動」は神経修飾的な近似。チャネルレベルでは ATP 低下は
むしろ興奮性を下げる。後者は将来 DNN 相当の別チャンネルへ移す。

**開発中に見つけたバグ**（同型の実装で繰り返さないこと）:
`c.height` に物理ピクセル数を代入すると HTML 属性も書き換わるため、
直後に属性を読んで論理高さとして使うと devicePixelRatio 倍に
なる。描画領域の上 1/3 しか表示されない。論理高さは
`dataset` に退避してから使う。
