# 長時間実験: 10万ティック × 5シード（2026-08-11）

Demo 6「不在中の進行」の前哨実験。3,000ティック（夜間バッチの標準セット）
では見えないものを見る。

- 実行: `runs/longrun_20260811_0906/`（`scripts/longrun_sim.ps1`）
- コミット: `88797b9`（Demo 8.5 完了後）
- 所要: **39.6 秒**（5シード × 10万ティック、14並列）
- レポート: `runs/longrun_20260811_0906/report.html`（自己完結、画像6枚を data: URI で埋込）

**植物の場化で個体走査が消えたため、10万ティックが40秒で回る。**
バックグラウンドで放置する前提だったが、その必要がなくなった。

## 分解能の問題と、プローブの追加

SimRunner の個体数系列は1ランあたり2,000点に間引かれる（10万ティックなら
**50ティック間隔**）。一方、安定判定に使う `MinHerbivores` は毎ティック更新される。
そのため「系列上の最小値は2なのに `guildExtinct=1/5`」という食い違いが出た。

50ティック未満の事象を見るために `tools/LongrunProbe` を追加した
（個体数は毎ティック、場の平均は50ティックごとに測る使い捨てプローブ）。

## 1. 生態系は10万ティック安定していたか

**絶滅したシードは無い。**

| 種 | 結果 |
|---|---|
| 狼 | 0になった区間なし（最小 3〜4） |
| 草 | 0に近づかず（最小は適性セルあたり 0.067〜0.081、定常の約半分） |
| 草食ギルド | **1シードで1ティックだけ 0**（seed 1000、tick 89873）。他4シードは最小1 |

seed 1000 の事象は **tick 89873 の1ティックのみ**で、次のティックには回復している。
10万ティック中の1ティック＝0.001%。

### `guildExtinct` の判定基準は長時間実験に使えない

現在の基準は `MinHerbivores == 0`（`SeedResult.cs`）。3,000ティックでは
妥当だが、10万ティックでは**健全な系でも遅かれ早かれ必ず引っかかる**。
個体数が一桁で推移する系では、1ティックだけ0になる確率は時間に比例して積み上がる。

実際この基準のせいで `m5Pass=false` / `stabilityViolations=1` が出ているが、
中身は「1ティックの瞬断」であって全滅ではない。

**対処案（未実施、判断待ち）**: 「N ティック連続で0」を全滅の定義にする。
N は個体の再供給間隔より十分長く取る。プローブは既に連続区間長を測っている。

## 2. 死の場（τ≈333）は飽和したか

**飽和する。ただし単調な立ち上がりではなく、オーバーシュートしてから緩和する。**

| tick | 死の場平均 | 定常比 |
|---:|---:|---:|
| 50 | 0.000000 | 0.00 |
| 100 | 0.000607 | 0.14 |
| 200 | 0.005861 | 1.34 |
| 300 | 0.006833 | 1.56 |
| **500** | **0.007223** | **1.65 ←ピーク** |
| 750 | 0.006291 | 1.44 |
| 1,000 | 0.005689 | 1.30 |
| 2,000 | 0.005388 | 1.23 |
| 3,000 | 0.004465 | 1.02 |
| 10,000 | 0.003984 | 0.91 |
| 100,000 | 0.004379 | 1.00 |

定常値 = **0.004380**（後半5万ティックの平均）。

**τ≈333 から予想される「1,500ティックで定常」は、上りだけを見た予想としては
正しいが、実際の系列はそうならない。** ピークは tick 500 付近で定常の **1.65倍**、
定常帯に落ち着くのは **約3,000ティック**、以後は揺らぐだけになる。

理由は場の時定数ではなく**書き込み量の変動**にある。立ち上がり期は個体数が
過剰（tick 0〜10,000 の草食獣ブロック平均 15.04 に対し、以後は 9〜11）で
餓死が集中し、死の場への書き込みが定常期より多い。場が飽和するより先に
**個体数が過剰から定常へ落ちる**過程が支配的だった。

他の場との比較:

| 場 | 定常到達 | 立ち上がりの形 |
|---|---|---|
| 踏み荒らし（τ≈50） | **約200ティック** | 単調、オーバーシュートなし |
| 草（植生場） | **約750ティック** | 単調 |
| 死（τ≈333） | **約3,000ティック** | tick 500 で1.65倍のオーバーシュート |

**時定数の順（50 < 333）と整定時間の順（200 < 3,000）は一致するが、比率が合わない。**
τ比 6.7倍に対し整定時間比は15倍。差はオーバーシュートぶんである。

草食獣 −6.9% / 狼 +7.3% / 恐怖 +6.9% は一見ドリフトに見えるが、
**シード間SDと同程度かそれ以下**（草食獣の変化 0.78 に対し SD 1.08）で、
5シードでは区別できない。ブロック平均が単調でないこと（狼は
40,000–50,000 の 12.55 をピークに戻っている）からも、
トレンドではなく捕食者-被食者の長周期の振動と見るのが自然。

**ただし 5シードは48シード規約を下回る**ので、これは結論ではなく観察である。
差を主張したいなら48シードで測り直すこと。

## 方法論の記録

**瞬時値が「定常±10%帯」に入った時刻を整定時間にしてはいけない。**
定常な系でも系列は揺らぎ続けるので帯を出入りし、「最後に帯を出たティック」は
定常な系でも必ず終端付近になる。最初にこれを実装して、
「整定時間 95,000〜100,000ティック」という無意味な表を作った。
揺らぎとトレンドを分けるには区間平均を並べる。

**warmup 除外は指標ごとに要否が違う。** 最小値の集計には必要だが、
**立ち上がりそのものを見る系列には有害**。プローブの初版は場のトレースを
warmup 後から取っており、最初のサンプル（tick 350）が既に定常の1.66倍という、
上昇過程の見えない表になっていた。
