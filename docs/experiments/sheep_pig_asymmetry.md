# 羊と豚に系統差はあるか（2026-08-11）

**結論: 系統差は無い。中立浮動と区別できない（符号検定 p = 0.31）。**

## 観察の経緯

羊と豚は行動パラメータが完全に同一である（重みも初期値も同じ）。
Demo 5b 以来「中立ドリフト」として扱ってきた。非対称の候補になりうるのは
狼の獲物選択（PreyField 経由）と初期配置の2つしかない。

longrun（5シード × 10万ティック、`docs/experiments/longrun_100k.md`）で
**5シード全部で豚が優勢**（プール比 1.028、比の範囲 1.005〜1.063）という
観察が出た。5/5 が同方向なので、対称性が破れている可能性が疑われた。

これを48シード規約（CLAUDE.md）で判定する。

- 帰無仮説: 中立浮動。どちらが多くなるかはコイン投げで、5/5 は
  効果が無くても 2 × (1/2)^5 = **6.25%** の確率で起きる

## 手順

### 計測コードの追加（シミュレーション本体には触れていない）

SimRunner は草食獣を合算した `meanHerbivoresPerTick` しか出しておらず、
種別の内訳が無かった。集計のみを追加した:

- `SeedResult.MeanSheepPerTick` / `MeanPigPerTick`
- `Runner.RunOne` の warmup 後ブロックで `world.SheepCount` /
  `world.PigCount` を加算（カウンタの読み出しだけなので O(1)。
  ティック時間 = M1 の基準値を汚さない）
- `summary.json` に `speciesBySeed` 配列（シードごとの sheepMean / pigMean）と、
  条件ごとの集計値 `meanSheepPerTick` / `meanPigPerTick`

**シードごとに残すことが必要だった。** 集計値だけでは
「何シードで豚が優勢か」という符号検定ができない。

### ContentHash が変わらないことの実測確認

集計の追加が挙動に影響していないことを、変更前後で同一条件を回して確認した
（5シード × 2000ティック）:

**不一致 0 / 5。** 決定論は無傷。

### 計測

```
dotnet run -c Release --project tools/SimRunner -- --seeds 48 --ticks 20000 --images 0 --out runs/sheep_pig_48s20k
scripts/analyze_sheep_pig.ps1
```

warmup 300ティック以降の時間平均を種別に取る。所要は48シードで約1分。
（`runs/` は gitignore 対象なので生データは残らない。再現は上のコマンドで行う）

## 結果

| 指標 | 値 |
|---|---:|
| 豚が優勢だったシード | **20 / 48**（羊 28、同数 0） |
| プール比（豚/羊） | **1.0029**（羊 6.2199 / 豚 6.2381） |
| シードごとの比 | 平均 1.0055、**SD 0.0846**、範囲 0.8758〜1.2082 |
| 差（豚−羊） | 平均 +0.0182 頭、SD 0.5084、t(47) = 0.248 |
| **符号検定（p=0.5、両側）** | **p = 0.3123**（片側 P(X≤20) = 0.1562） |
| 差の95%信頼区間 | −0.1294 〜 +0.1658 頭（羊平均比 **−2.1% 〜 +2.7%**） |

5シードとの対比:

| 指標 | 5シード × 10万 | **48シード × 2万** |
|---|---:|---:|
| プール比（豚/羊） | 1.028 | **1.0029** |
| 豚が優勢なシード | 5/5 | **20/48** |
| 比の範囲 | 1.005〜1.063 | 0.876〜1.208 |

## 判定

**p = 0.3123 ≧ 0.05。系統差は無い。** longrun の 5/5 は偶然である。

p ≧ 0.05 のため、手順で条件付けていた追加調査（狼の捕食イベントの
対象種別の内訳）は実施していない。

## 解釈

**5シードの見かけの効果は、48シードの信頼区間の外にある。**
5シードのプール比 1.028（＝+2.8%）に対し、48シードの95%CIは
**−2.1% 〜 +2.7%**。5シードで見えた大きさの効果は、もう否定できる。

ただし「差がゼロである」ことを示したわけではない。
48シード × 2万ティックの**検出下限は比にして約3.3%**
（検出力80%、SD 0.0846 から算出）。これより小さい系統差があっても
この標本数では見えない。狼の獲物選択に微小な非対称が残っている
可能性は、この実験では排除できていない。**否定したのは
「longrun が示唆した大きさの効果」であって、非対称そのものではない。**

符号は指標によって逆を向く。優勢シード数は羊寄り（28/48）、
プール比はごくわずかに豚寄り（1.0029）。**指標間で符号が一致しないのは、
効果が無い時の典型的な見え方である。**

### 48シード規約が効いた4例目

- Demo 8 第2段: 墓場の植物密度比 1.166 → 0.523
- Demo 5b: 狼の全滅率 0/5 → 3/48
- longrun 仮説B: 振動のシード間相関（別要因）
- **本件: 豚優勢 5/5 → 20/48**

**「全シードが同方向」は標本数が少なければ簡単に起きる。**
5シードで5/5 が揃う確率は、効果がゼロでも 6.25% ある。
20回に1回以上引く目であり、これを根拠に仮説を立ててはいけない。

### 有意でない結果には検出下限を添える

「p ≧ 0.05 だから差は無い」で止めると、
「測っていないだけ」と「本当に無い」が区別できない。
本件は 95%CI と検出下限を併記することで、
**否定できた効果の大きさ（2.8%）と、否定できていない範囲（3.3%未満）**を
分けて記録している。以後の否定的結果もこの形で残す。
