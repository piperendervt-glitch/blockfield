## 1. パネルの行構成

```
1行目  FPS: 72.0   Tick: 2.06ms   Bake: 27ms
2行目  Speed[R-A]: 0.030 m/s (1/3)  = 0.04cm/frame   Max: 0.140
3行目  Cell[L-X]: 8.0cm (1/3)   34x28x42=39984   Solid: 19674 (壁12970+縁6704)
4行目  View[L-Y]: 微粒子 (1/3)   n=3000   size=1.0cm   t=1234
5行目  Jelly[R-B]: 15cm (2/3)   pulse=27   swim=0.040   flow=0.012   swim/flow=3.33
```

`(1/3)` は「今が3段階のうち1段目」。**自分がどの段階にいるかは必ずこの分数で確かめる**
（前回、現在値が出ておらず何と何を比べているか分からなくなった）。

|---|---|---|

## 2. 判定項目と読む数値

### 項目3: クラゲの姿勢（前回 △）

**読むもの: パネルではなく目視。**

- 傘の底（リム）が水平か。**傾いて見えたら NG**
  - リムは平面に固定してあるので、構造的に傾かないはず
- 真横・真下・真上の3方向から見て、傘が消えないか
  - 両面描画にしてあるので、どこからでも見えるはず
- 拍動で「すぼまって背が高くなる」動きが見えるか
- 収縮が片側に寄って見えるのは**仕様**（興奮波がリングを巡る。半径に出している）

### 項目4: 傘径と流速の比（前回 未実施）

**読むもの: 5行目の `swim/flow`。**

`swim` = 直近1拍動の平均遊泳速度、`flow` = 同じ区間で流れに運ばれた平均速度。
どちらも**平均**（瞬時値は拍動の位相で 0.19〜0.0004 m/s まで振れて使えない）。

手順:

1. 右手A で流速を **0.03** に合わせる（2行目が `(1/3)`）
2. 右手B を回して 10cm → 15cm → 25cm。**各段で5秒待ってから** `swim/flow` を読む
   - 待つ理由: 平均の窓が1拍動 = 1.0 秒。切り替え直後は 0.00 が出る
   - 期待: 傘径を変えても `swim` は 0.040 のまま（この段では傘径と速度は独立。
     相関させるのは抗力係数の逆算後 — prereg jelly_1 §9）
3. 右手A を **0.08** にして 2 を繰り返す
4. 右手A を **0.15** にして 2 を繰り返す

判定: `swim/flow` が 1 を **超えていれば自力が勝っている**（漂っているのではなく泳いでいる）。
1 を下回る流速がどこかを見る。前回の観察「クラゲなら 0.03 m/s」が正しければ、
0.03 で比が 1 を超え、0.15 で下回るはず。

### 項目2(a): 流れの高さ分布（前回 △）

**読むもの: パネルではなくログ。** 焼き込みのたびに1行出る:

```
[Aquarium] 高さ分布 (床からの高さ: 固体率(うち縁) 平均流速m/s): [0.40m 42%(10%) 0.034] [1.60m 34%(10%) 0.036] ...
```

括弧内は外周シール（水槽の縁）ぶんで、1セル厚のリングなので高さによらずほぼ一定。
**残りが実際の壁・家具**である。

装着中は読めないので、**目視だけしておく**:

- 天井近くまで粒子が動いているか。動いていない高さを覚えておく

セッション後にログの帯を突き合わせる。切り分けは:

- 固体率（括弧の外）が高い帯 → 焼き込みが壁だと判断している（スキャンメッシュの問題）
- 固体率が低いのに平均流速が小さい帯 → 境界ランプで消えている（ランプ幅の問題）

前回の実測では 1.60m でも平均流速 0.036 で 0.88m と同じだった。
**場は天井付近まで生きている**ので、見えないなら粒子側の問題である。

同じ行に `床=` `天井=` `格子Y=` も出るので、格子が部屋の高さを覆えているかも分かる。

### 項目2(b): 鉛直の循環

**この段では出ない。仕様。**
流れは ψ の curl から作った等方な渦なので、床から天井への持続した循環は生じない。
`FlowParams.BuoyancyWeight` は 0 のまま置いてある。
温度差による浮力項を入れるのは Phase D で、そこで初めて鉛直の循環が出る。

## 付録: 固体セルの内訳（2026-08-16 実測）

「空中の固体率が 34〜49% は多すぎないか」を、端末の生メッシュ
(`room_mesh_archive_20260816_141117.bin`, 16088頂点 32544三角形) で
焼き込みを再現して確かめた。格子・バウンズとも実機と一致する。

| セル | 格子 | メッシュ由来 | 外周シール | 部屋の外側の水 | 焼き込み厚 |
|---|---|---|---|---|---|
| 8.0cm | 42x28x34=39984 | 12970 (32.4%) | 6704 (16.8%) | 289 (1.4%) | 1.01セル |
| 6.5cm | 52x34x42=74256 | 21013 (28.3%) | 10256 (13.8%) | 2584 (6.0%) | 1.08セル |
| 5.5cm | 61x40x49=119560 | 30341 (25.4%) | 14184 (11.9%) | 5174 (6.9%) | 1.12セル |

結論: **仕様どおり。過剰な焼き込みは無い。**

- **厚みは1セル。** 三角形の総面積 82.2m² を セル² で割ると 12846 セル。
  実際は 12970 で比 **1.01**。薄い面を厚い固体にしてはいない
- **外周シールは1セル厚のリング。** 層あたり 2(W+D)-4 セルで、
  8cm なら 148/1428 = 10.4%。高さによらずほぼ一定
- **部屋の外側は 1.4% しかない。** 主軸合わせが効いている
- 空中の固体率が高いのは**部屋に本当にそれだけ面があるから**。
  素の直方体なら 40.1m² のところ、スキャンは 82.2m²（家具と雑多な面で2倍）。
  1セル厚の殻が 82.2m² × 8cm = 6.58m³ を占め、格子 20.5m³ の 32% になる

**固体率はセルサイズに比例して下がる**（殻は常に1セル厚だから）。
空間を空けたければ左手Xでセルを細かくする。ただし細かくすると
すれすれの面が2セルにまたがる割合が増え（比 1.01 → 1.12）、
部屋の外側の水も増える（1.4% → 6.9%）。
